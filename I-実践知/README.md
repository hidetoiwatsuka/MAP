# I. 実践知

知識を実際の場面で発揮する能力。アリストテレスのいう「フロネーシス（実践的知恵）」。

## 核となる概念

**知識と経験の統合による行動知（フロネーシス）** — 実践知は「知っている」から「できる」への変換を扱う。身体技能・対人スキル・判断力は理論だけでは習得できず、実際の状況の中で試行・フィードバック・修正を繰り返すことで獲得される。どの分野でも「手を動かした経験」が理解の密度を決定的に変える。

## サブカテゴリ

- [I2 対人技能](./I2-対人技能.md) — 傾聴・交渉・ファシリテーション・コーチング
- [I3 判断力](./I3-判断力.md) — 臨床推論・意思決定・リスク評価
- [I4 メタ認知](./I4-メタ認知.md) — 自己モニタリング・学習方略・批判的思考

## 深さ・学習方針

- **深さ：第2層**
- **理由：** ここはAIが最も代替できない領域。身体技能、交渉、即座の判断——全部、体と対人経験を通じてしか獲得できない関数。臨床はまさにこれ。
- **具体的に何を：** 臨床コミュニケーション、交渉の基本原則、意思決定のフレームワーク（ヒューリスティクスとその限界）、身体的スキル
- **校正：** 臨床実習、実際の人間関係、ストレス下での判断経験。

## 入門のための前提知識

このカテゴリに入門するために最低限知っておくべきこと。

| 領域 | 知っておくべきこと |
|------|-------------------|
| 身体の基本（[C-生命・医療科学](../C-生命・医療科学/README.md)との接点） | 自分の身体がどう動くかの基本感覚、筋肉・骨格の大まかな仕組み |
| 対人関係の基本 | 言語コミュニケーションと非言語コミュニケーション（表情・声のトーン）の存在 |
| 意思決定 | 人は常に選択をしている、トレードオフの概念、「完璧な判断」は存在しない |
| メタ認知 | 「自分が何を知っていて何を知らないかを知る」という二階の思考 |
| フィードバック | 行動→結果→修正 のループ、PDCAやtrial-and-errorの直感 |
| 感情の存在 | 感情が判断に影響する、感情を認識すること自体がスキルである |

> 実践知は「知識を行動に変換する」ための分野。他のカテゴリが「知る」ことに焦点を当てるのに対し、Iは「やる」に焦点を当てる。自分の身体・感情・認知の存在を意識できることが出発点。最も「座学」では足りないカテゴリ。
