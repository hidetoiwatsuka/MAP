# MAP

> Personal knowledge vault by [hidetoiwatsuka](https://github.com/hidetoiwatsuka)

## なぜこの地図が必要なのか

AIが定型的な知的作業を代替し始めている。
この変化が意味するのは、「指示に従って正確に処理する」タイプの知的労働の価値が急速に下がるということだ。

残るのは**意思決定**である。
何を作るか、何を捨てるか、何を優先するか。これらの判断はAIに丸投げできない。なぜなら、意思決定とは「正解のない問いに対して、根拠と価値観に基づいて立場を取ること」だからだ。

意思決定の質を決めるのは**議論**の力である。
自分の中で完結する思考も他者やAIとの対話も、本質は同じである。異なる領域の知見を繋ぎ、包括的に考え、さまざまな可能性を見出す。これが議論の核心であり、意思決定の精度を左右する。

議論の力は、3つの要素に分解できる：

| 要素       | 役割                         |
| -------- | -------------------------- |
| **言葉**   | 精密に考え表現し、正確に伝える道具          |
| **知識**   | 議論の中で参照できる事実・理論・事例の広さと深さ   |
| **概念理解** | 個別の知識を抽象化し、分野を横断して構造的に捉える力 |

言葉が曖昧なら議論は空回りする。知識が狭ければ選択肢が見えない。概念理解がなければ、異なる分野の知見を繋げられない。

**MAPは、3つの要素のうち「知識」と「概念理解」の土台を作るためのものだ。**

人間の知識の全体像を、分野の依存関係と構造を意識しながら地図として描くことで、「自分が何を知っていて、何を知らないのか」を可視化する。それが、意思決定行う時に強い武器になる。

## 具体的な使用方法

> **大原則：** 全分野で「AIに正しい問いを投げ、返ってきた答えの妥当性を判断できるレベル」を目指す。

## 理解の3層モデル

| 層               | 定義                               | 目安                             |
| --------------- | -------------------------------- | ------------------------------ |
| **第1層：概念的地図**   | その分野が何を扱い、なぜ存在し、他分野とどう繋がるかを説明できる | 教科書の目次を見て構造を語れる                |
| **第2層：操作可能な理解** | AIの出力の妥当性を判断でき、最小限の実装ができる        | その分野の人間と会話が成立し、小さなプロジェクトを完遂できる |
| **第3層：専門的習熟**   | AIなしで一人で完遂できる。判断に迷いがない           | 本業レベル。状況を即座に判断し、対処できる          |


## 勉強の仕方：4ステップ

1. **入門書で構造を掴む** — その分野の専門家が初学者向けに書いた本を一冊通す。啓蒙書ではなく、学問としての骨格が見える本。目的は中身の暗記ではなく、「この分野は何を問題にしていて、どういう構造で成り立っているか」の把握。
2. **一つ手を動かす** — その分野で小さなプロジェクトを一つ通過する。自分で入力を選び、自分で処理を組み立て、出力の妥当性を自分で判断する。この経験が、AIの出力に対して「合ってる」「おかしい」と判断できる基準を作る。
3. **AIと壁打ちする** — 手を動かして出た疑問をAIにぶつけ、答えを自分の地図に照らして評価する。納得できれば地図が精錬される。納得できなければさらに掘る。このループが学習の本体。
4. **MAPに書き込む** — 得た理解をMAPに反映し、地図を更新する。他分野との接続が見えたらリンクを張る。地図が育つほど、次の分野に入る時の初速が上がる。

**入門書の選び方：** 「その分野の専門家が初学者向けに書いた本」がベスト。一般向けの啓蒙書（面白く読めるが骨格が見えない）ではなく、学問の構造が透けて見える本を選ぶ。各カテゴリで同じ質の入門書を一冊ずつ通過すれば、第1層は確実に埋まる。そこから第2層に上げるかは深さ設定に従う。


## カテゴリ別：深さ・理由・校正方法

### A — 形式科学（論理・数学・計算）

- **深さ：第2層**
- **理由：** 全分野の言語。ここが曖昧だと他の全カテゴリでAIの出力を評価できない。論理的誤謬を見抜けないと、どの分野でも騙される。
- **具体的に何を：** 命題論理・述語論理の操作、確率・統計の直感的理解、線形代数の概念（ベクトル空間、行列変換）、微積分の意味的理解
- **校正：** 証明を自分で書く。統計的主張の誤りを見抜く練習。

### B — 自然科学（物理・化学・生物）

- **深さ：第2層（生物は第3層寄り）**
- **理由：** 現実世界のルールブック。工学もゲノムもロボティクスも、ここが土台。医学の基礎でもある。
- **具体的に何を：** 力学・熱力学・電磁気の基本原理、化学結合と反応速度の概念、分子生物学のセントラルドグマ、進化の仕組み
- **校正：** 物理シミュレーションを一つ書く。化学反応の帰結を予測してから確認する。

### C — 生命・医療科学

- **深さ：第3層（本業）**
- **理由：** キャリアの実装先。
- **具体的に何を：** 解剖・生理・病理・薬理の全体系。臨床推論。カテーテル技術。研究方法論。
- **校正：** 臨床実習、研究、試験。6年間＋研修で強制的に積まれる。

### D — 工学・技術（情報・機械・電気・ロボティクス）

- **深さ：第2層**
- **理由：** 「作れる」能力の基盤。ロボットを作る、ハッキングする、データを解析する——全部ここ。AIに設計を出させても、それが物理的・技術的に成立するか判断するには原理の理解がいる。
- **具体的に何を：** C言語→アセンブリ→Pythonの基盤、回路の基本原理、制御理論の概念、ネットワークの仕組み、機械設計の制約条件
- **校正：** コードを書いて動かす。回路を一つ組む。CTFに参加する。

### E — 人間科学（社会学・言語学・認知科学）

- **深さ：第1〜2層**
- **理由：** 人間の行動を予測する関数の材料。対人関係、チームマネジメント、組織運営。
- **具体的に何を：** 認知バイアスの主要パターン、言語が思考を制約する仕組み、集団行動の力学
- **校正：** 自分の判断バイアスを日常で検出する。

### F — 社会制度（経済・法・経営）

- **深さ：第2層**
- **理由：** 「お金を稼げる」はここ。クリニック経営、投資判断、法的リスクの評価。
- **具体的に何を：** ミクロ経済（需給・価格・インセンティブ）、会計の基本（PL・BS・CFが読める）、契約と知的財産の基礎、組織設計の原則
- **校正：** 財務諸表を一つ読んで分析する。事業計画を一つ書いてみる。

### G — 人文学（哲学・歴史・文学）

- **深さ：第1〜2層**
- **理由：** 「なぜそうなっているか」の時間軸を与える。技術も制度も、歴史的文脈なしには現在の構造が理解できない。哲学は思考そのものの関数を検証するメタツール。
- **具体的に何を：** 西洋哲学の主要な転換点（ソクラテス→デカルト→カント→実存主義→分析哲学）、科学史（なぜ専門分化が起きたか）、主要な文明の興亡パターン
- **校正：** 自分の理念体系を哲学史に位置づけてみる。歴史的事例で自分のモデルを検証する。

### H — 情報・メディア

- **深さ：第1層**
- **理由：** 情報の流通構造を理解する。フェイクニュースの見抜き方、メディアバイアスの構造、情報の非対称性。判断の入力が汚染されていたら出力も狂う。
- **具体的に何を：** メディアリテラシーの基本原則、情報の信頼性評価フレームワーク、アルゴリズムによる情報選別の仕組み
- **校正：** ニュースソースを複数比較する習慣。

### I — 実践知（身体・対人・判断）

- **深さ：第2層**
- **理由：** ここはAIが最も代替できない領域。身体技能、交渉、即座の判断——全部、体と対人経験を通じてしか獲得できない関数。臨床はまさにこれ。
- **具体的に何を：** 臨床コミュニケーション、交渉の基本原則、意思決定のフレームワーク（ヒューリスティクスとその限界）、身体的スキル
- **校正：** 臨床実習、実際の人間関係、ストレス下での判断経験。

### J — 横断領域（システム思考・デザイン・データ科学・倫理）

- **深さ：第2層**
- **理由：** 関数の合成そのもの。分野を横断してパターンを見抜くためのメタスキルがここに集約されている。MAPの設計思想自体がシステム思考の産物。
- **具体的に何を：** システムダイナミクス（フィードバックループ、創発）、データサイエンスのワークフロー（収集→前処理→分析→解釈）、研究倫理・生命倫理の主要論点、デザイン思考のプロセス
- **校正：** 複数分野のデータを統合して一つの分析を行う。倫理的ジレンマを自分のフレームワークで分析する。

### K — 地理・地政学

- **深さ：第1層**
- **理由：** 世界の物理的・政治的制約条件。なぜある国が豊かで別の国が貧しいか、なぜ戦争が起きるか、なぜ資源が偏在するか。意思決定の背景情報として必要。
- **具体的に何を：** 主要国の地理的制約と戦略的利害、資源分布の基本、国際関係の主要フレームワーク
- **校正：** 国際ニュースを地政学的フレームで読む。

### L — 文化・生活

- **深さ：第1層**
- **理由：** 人間の日常を構成する具体の世界。ここを知らないと「仕事をしている人たちの気持ち」がわからない。食、服飾、スポーツ、遊び——全部、人間の欲求の具体的な表出。
- **具体的に何を：** 主要な文化圏の価値観の違い、日常生活を構成する産業の仕組み、趣味・娯楽の多様性
- **校正：** 異文化での生活経験（今のブダペスト生活）、多様な人間との交流。

## Obsidian ユーザーへ

このリポジトリは **Obsidian vault としてそのまま開けます**。

### PDF の扱い

PDF は `.gitignore` で除外されています。ローカルの Obsidian では `![[file.pdf]]` が通常通り動きますが、**Git には入りません**。PDF は授業スライドや教科書など「参照元」であってマップ本体ではないため、この設計は意図的なものです。

- PDF を Attachments に追加 → Obsidian でそのまま使える、git には入らない
- GitHub 上では PDF リンクは切れるが、それは許容範囲

### wikilinks の変換

Obsidian の `[wikilinks](00_inbox/wikilinks.md)` は GitHub 上では機能しないため、push 前に以下のスクリプトで標準 Markdown リンクに変換してください。

**実行方法**

```bash
python3 convert_obsidian_links.py
```

Python 3.10 以上が必要です。追加ライブラリは不要です。

**何をするか**

| 変換前 | 変換後 |
| --- | --- |
| `[Note Name](00_inbox/Note%20Name.md)` | `[Note Name](path/to/Note%20Name.md)` |
| `[[Note\|表示名]]` | `[表示名](path/to/Note.md)` |
| `![[image.png]]` | `![image.png](path/to/image.png)` |
| `![[document.pdf]]` | `![[document.pdf]]` |

- vault 内の全ファイルを自動でインデックス化し、相対パスで正しくリンクします
- macOS の NFD ファイル名（`é` などのアクセント文字）にも対応しています
- リンク先のノートがまだ存在しない場合は、`00_inbox/` にプレースホルダーを自動生成してリンクを解決します
- スペースや特殊文字はすべて URL エンコード（`%20` 等）されます

**推奨ワークフロー**

```
Obsidian で編集
    ↓
python3 convert_obsidian_links.py
    ↓
git add . && git commit && git push
```
