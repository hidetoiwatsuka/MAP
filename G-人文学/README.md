# G. 人文学

意味・価値・解釈・歴史を扱う知識。事実の記述ではなく、理解・解釈・評価を目指す。

## 入門のための前提知識

このカテゴリに入門するために最低限知っておくべきこと。

| 領域 | 知っておくべきこと |
|------|-------------------|
| 世界史の大枠 | 古代文明（メソポタミア・エジプト・ギリシャ・ローマ・中国）→中世→ルネサンス→近代→現代 の流れ |
| 主要な宗教 | キリスト教・イスラム教・仏教・ヒンドゥー教・ユダヤ教 の存在と大まかな分布地域 |
| 哲学の出発点 | 「なぜ？」と問うこと自体が学問になるという認識、ソクラテス・プラトン・アリストテレスの名前と「古代ギリシャが西洋哲学の出発点」であること |
| 文学とは何か | フィクションとノンフィクションの区別、詩・小説・戯曲というジャンルの存在 |
| 読解力 | 長い文章を読んで論旨を追えること、比喩や修辞を字義通りに取らないこと |
| 地理（[K-地理・地政学](../K-地理・地政学/README.md)からの依存） | 世界地図上で主要文明圏・宗教圏の位置がわかること |
| 時間感覚 | 紀元前/紀元後（BC/AD）、世紀の数え方、年表を読めること |

> 人文学は「人間が残してきた思想・物語・制度の意味」を読み解く分野。世界史の骨格と主要宗教の存在を知らないと、テキストの文脈が分からない。また、テキストを精読する能力自体が前提スキル。
