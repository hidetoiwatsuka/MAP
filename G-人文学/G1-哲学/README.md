# G1. 哲学

存在・知識・価値・言語・心の本質を問う学問。すべての学問の基礎にある問いを扱う。

## 核となる概念

**問いそのものを問う（概念の明晰化）** — 哲学は「知識とは何か」「正しいとはどういうことか」「存在するとはどういうことか」という、他の学問が前提にする概念を問い直す。この問いの力は他の分野の基礎を鍛え直し、思考そのものの精度を上げる。
