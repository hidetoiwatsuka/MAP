# L. 文化・生活

日常生活・身体・移動・遊び・軍事など、人間の実践的・物質的文化を扱う領域。

## 核となる概念

**人間の実践と欲求の物質的・文化的表出** — 食・服・住・遊び・移動——これらは人間の生物的欲求が文化・歴史・技術によって特定の形に組織化されたものである。「なぜこの形か」を問うと、地理・歴史・経済・社会のすべてが交差する。日常の物事を見る目が、学問知識と接続する入口になる。

## 深さ・学習方針

- **深さ：第1層**
- **理由：** 人間の日常を構成する具体の世界。ここを知らないと「仕事をしている人たちの気持ち」がわからない。食、服飾、スポーツ、遊び——全部、人間の欲求の具体的な表出。
- **具体的に何を：** 主要な文化圏の価値観の違い、日常生活を構成する産業の仕組み、趣味・娯楽の多様性
- **校正：** 異文化での生活経験（今のブダペスト生活）、多様な人間との交流。

## 入門のための前提知識

このカテゴリに入門するために最低限知っておくべきこと。

| 領域 | 知っておくべきこと |
|------|-------------------|
| 食の基本 | 三大栄養素（炭水化物・タンパク質・脂質）、調理の基本概念（加熱・発酵等） |
| 衛生の基本 | 食中毒の概念、手洗いの重要性、基本的な衛生管理 |
| 文化多様性 | 食文化・服飾・礼儀作法は地域や宗教で大きく異なること |
| 身体の基本（[C-生命・医療科学](../C-生命・医療科学/README.md)との接点） | 栄養が身体に影響する、運動の効果、睡眠の重要性 |
| 地理の基本（[K-地理・地政学](../K-地理・地政学/README.md)との接点） | 主要な国・地域の位置、文化圏の大まかな分布 |
| 経済の基本（[F-社会制度](../F-社会制度/README.md)との接点） | 商品と価格、市場の概念、観光産業の存在 |
| 歴史（[G-人文学](../G-人文学/README.md)との接点） | 食文化・ファッション・スポーツが歴史的に変遷してきたこと |

> 文化・生活は最も身近でありながら、体系的に学ぶ際には他カテゴリの知識が背景として必要。「なぜ日本人は米を食べるのか」を答えるには地理・歴史・農学の知識が要る。入門のハードル自体は低いが、深掘りすると全カテゴリに接続する。
