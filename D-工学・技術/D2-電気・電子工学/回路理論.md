# 回路理論

## 直流回路

### 基本法則
- オームの法則（V = IR）
- キルヒホッフの電流則（KCL）：節点に流入する電流の和 = 0
- キルヒホッフの電圧則（KVL）：閉ループの電圧の和 = 0

### 回路解析
- 節点電位法（node voltage method）
- 網目電流法（mesh current method）
- 重ね合わせの定理
- テブナンの定理・ノートンの定理
- 最大電力伝達条件（負荷抵抗 = テブナン抵抗）

## 交流回路

### 正弦波と複素表示
- 正弦波電圧・電流の表示（振幅・角周波数・位相）
- フェーザー（位相ベクトル）表示
- インピーダンス（Z = R + jX）とアドミタンス

### RLC回路
- キャパシタンス（C）のインピーダンス（ZC = 1/jωC）
- インダクタンス（L）のインピーダンス（ZL = jωL）
- 直列・並列 RLC 回路の応答

### 共振
- 直列共振（ω₀ = 1/√LC、Q値）
- 並列共振
- バンドパスフィルタ・バンドリジェクトフィルタ

### 電力
- 有効電力（P）・無効電力（Q）・皮相電力（S）
- 力率（cosφ = P/S）
- 複素電力（S = VI* = P + jQ）

## 過渡解析

### 1次遅れ回路
- RC回路のステップ応答（τ = RC）
- RL回路のステップ応答（τ = L/R）
- 時定数の意味

### 2次回路（RLC）
- 特性方程式と固有振動数（ω₀）・減衰係数（α）
- 過減衰・臨界減衰・不足減衰

## ラプラス変換による回路解析
- s領域のインピーダンス（R・sL・1/sC）
- 初期条件の取り扱い
- 伝達関数 H(s) = Vout(s)/Vin(s)

## 四端子回路（二ポート回路）
- Zパラメータ・Yパラメータ・Hパラメータ
- 転送行列（ABCD行列）：縦続接続

## 三相交流
- 対称三相電源（Y接続・Δ接続）
- 線間電圧と相電圧の関係
- 三相電力（P = √3 VL IL cosφ）
- 不平衡三相回路
