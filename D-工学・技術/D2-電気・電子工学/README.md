# D2 電気・電子工学

電気・電磁現象を基礎に、回路・デバイス・システムを設計・分析する工学分野。

## 核となる概念

**電磁気現象の制御による信号・エネルギーの処理** — 電圧・電流の関係（回路理論）、電子の振る舞い（半導体）、波としての電磁場（通信・光）——これらはすべてマクスウェル方程式という一つの枠組みの異なる側面。「どう制御すれば望む信号・エネルギーを得られるか」が設計の核心。
