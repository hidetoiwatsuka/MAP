# オペレーティングシステム

## OSの役割と構造

### OSの機能
- ハードウェアの抽象化（デバイス管理）
- リソース管理（CPU・メモリ・I/O）
- プロセス管理・スケジューリング
- ファイルシステム
- セキュリティとアクセス制御

### カーネルの種類
- モノリシックカーネル（Linux：高性能）
- マイクロカーネル（minix・seL4：信頼性・モジュール性）
- ハイブリッドカーネル（Windows NT・macOS XNU）
- ユーザーランド vs カーネルランド（システムコール境界）

## プロセス管理

### プロセスとスレッド
- プロセスの状態（新規・実行可能・実行中・待機・終了）
- コンテキストスイッチ（PCB：プロセス制御ブロック）
- スレッド（カーネルレベル・ユーザーレベル・ハイブリッド）
- fork()/exec() システムコール（UNIX）

### スケジューリングアルゴリズム
- FCFS（先着順）・SJF（最短ジョブ優先）
- ラウンドロビン（タイムクォンタム）
- 優先度スケジューリング
- Linux CFS（Completely Fair Scheduler）

### 同期と排他制御
- 競合状態（race condition）とクリティカルセクション
- ミューテックス・セマフォ・スピンロック
- デッドロック（4条件：相互排除・Hold and Wait・非横取り・循環待機）
- デッドロック回避（銀行家アルゴリズム）

## メモリ管理

### 仮想メモリ
- ページング（固定長ページ）とセグメンテーション（可変長）
- ページテーブル（TLB：変換索引バッファ）
- 多段ページテーブル・Inverted Page Table

### ページ置換アルゴリズム
- FIFO・LRU・LFU・OPT（最適・参照頻度）
- クロックアルゴリズム（LRU近似）
- スラッシング（thrashing）と作業集合モデル

### メモリアロケーション
- 固定分割・可変分割（断片化問題）
- スラブアロケータ（Linux カーネル）
- ガベージコレクション（参照カウント・マーク＆スイープ・世代別GC）

## ファイルシステム

### ファイルシステムの構造
- ディレクトリ構造（ツリー構造・マウント）
- ファイル記述子・inode（UNIX）
- ファイルアロケーション（連続・連結・索引）

### 主要なファイルシステム
- ext4（Linux）・NTFS（Windows）・APFS（macOS）
- ZFS（Zettabyte File System）：Copy-on-Write・RAID-Z
- Btrfs（B-treeファイルシステム）：スナップショット

### ジャーナリング・一貫性
- ジャーナリングFS（Write-Ahead Log）
- FSCK（ファイルシステム整合性チェック）

## I/Oサブシステム

### デバイスドライバ
- カーネルモジュール（動的ロード可能）
- 文字デバイス・ブロックデバイス
- デバイスドライバのインターフェース

### I/Oスケジューリング
- CFQ（Completely Fair Queuing）
- Deadline・NOOP（SSD向け）・BFQ

## 仮想化・コンテナ

### ハイパーバイザー
- Type1（ネイティブ/ベアメタル：Xen・KVM・Hyper-V）
- Type2（ホスト型：VMware Workstation・VirtualBox）
- paravirtualization vs full virtualization

### コンテナ技術
- namespace（PID・network・mount・user 等の隔離）
- cgroups（リソース制限）
- Docker（コンテナランタイム）・Kubernetes（オーケストレーション）

## Linuxのシステムコール概要
- プロセス（fork・exec・wait・exit・kill）
- ファイル（open・read・write・close・mmap・ioctl）
- ネットワーク（socket・bind・listen・accept・connect・send・recv）
- メモリ（brk・mmap・munmap）
