# コンピュータネットワーク

## ネットワーク参照モデル

### OSI 7層モデル
1. 物理層（ビット伝送：ケーブル・無線）
2. データリンク層（フレーム・MAC アドレス・誤り制御）
3. ネットワーク層（IP アドレス・ルーティング）
4. トランスポート層（TCP/UDP・ポート番号）
5. セッション層（セッション管理）
6. プレゼンテーション層（データ表現・暗号化）
7. アプリケーション層（HTTP・DNS・SMTP）

### TCP/IP モデル（4層）
- ネットワークアクセス層（物理＋データリンク）
- インターネット層（IP）
- トランスポート層（TCP・UDP）
- アプリケーション層（HTTP・DNS 等）

## IPネットワーク

### IP アドレスとサブネット
- IPv4（32ビット）・IPv6（128ビット）
- CIDR（クラスレスドメイン間ルーティング）
- NAT（ネットワークアドレス変換）・PAT
- プライベートアドレス（RFC 1918）

### ルーティング
- スタティックルーティング
- ダイナミックルーティング（RIP・OSPF・BGP）
- BGP（Border Gateway Protocol）：インターネットの経路制御
- MPLS・SD-WAN

### TCP と UDP

#### TCP（Transmission Control Protocol）
- 接続指向・信頼性保証・フロー制御・輻輳制御
- 3ウェイハンドシェイク（SYN→SYN-ACK→ACK）
- スライディングウィンドウ・タイムアウト再送
- 輻輳制御（スロースタート・輻輳回避・高速再送）

#### UDP（User Datagram Protocol）
- コネクションレス・低レイテンシ・信頼性なし
- 用途：DNS・DHCP・ストリーミング・VoIP・QUIC

## アプリケーション層プロトコル

### Web通信
- HTTP/1.1・HTTP/2（多重化・ヘッダ圧縮）・HTTP/3（QUICベース）
- HTTPS（TLS/SSL：暗号化・認証）
- WebSocket（双方向通信）

### 名前解決
- DNS（ドメインネームシステム）：再帰的・反復的クエリ
- DNS レコード（A・AAAA・CNAME・MX・NS・TXT）
- DNSSEC（DNSセキュリティ拡張）

### メール
- SMTP（送信）・POP3/IMAP（受信）
- SPF・DKIM・DMARC（なりすまし対策）

### ファイル転送・管理
- FTP・SFTP・SCP（ファイル転送）
- SSH（リモートシェル・トンネリング）
- SNMP（ネットワーク管理）

## 無線LAN（Wi-Fi）
- IEEE 802.11 規格（a/b/g/n/ac/ax：Wi-Fi 6/6E、be：Wi-Fi 7）
- CSMA/CA（衝突回避方式）
- MIMO・MU-MIMO・OFDMA

## ネットワーク機器
- ハブ（リピータ）・スイッチ（L2・L3スイッチ）・ルータ
- ファイアウォール（パケットフィルタリング・SPI・NGFW）
- ロードバランサー（L4・L7）
- プロキシサーバー（フォワード・リバースプロキシ）

## CDN・エッジコンピューティング
- コンテンツデリバリネットワーク（CDN）：地理的に近いサーバーから配信
- エッジコンピューティング：データ発生源の近くで処理
- Cloudflare・Akamai・AWS CloudFront

## ネットワーク仮想化
- VLAN（仮想LAN）・VXLAN（仮想L2のトンネリング）
- SDN（ソフトウェア定義ネットワーキング）：OpenFlow
- NFV（ネットワーク機能仮想化）：vRouter・vFirewall
- Service Mesh（Istio）：マイクロサービス間通信管理
