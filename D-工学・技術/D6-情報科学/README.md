# D6 情報科学

コンピュータシステムの構成・動作・設計・応用を扱う学問分野。

## 核となる概念

**抽象化の積み重ね（レイヤー構造）** — 情報科学は「物理→電気→論理ゲート→機械語→OS→アプリケーション」という抽象化の層を積み重ねることで成立している。各層は下の層の詳細を隠蔽し、上の層に単純なインターフェイスを提供する。どのレベルで議論しているかを常に意識することが理解の鍵。
