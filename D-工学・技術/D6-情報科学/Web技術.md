# Web技術

## フロントエンド

### 基盤技術
- HTML5（セマンティクス、アクセシビリティ、Web API）
- CSS3（Flexbox、Grid、アニメーション、変数）
- JavaScript（ES2020+、非同期処理、モジュール）
- TypeScript（型システム、型推論、ジェネリクス）

### フレームワーク
- React（仮想DOM、Hooks、コンポーネント設計）
- Vue.js（リアクティビティ、Options API / Composition API）
- Angular（DI、RxJS、テンプレート）
- Svelte（コンパイル時最適化）
- Next.js / Nuxt.js（SSR、SSG、ISR）

### ビルドツール
- Vite、webpack、Rollup、esbuild
- Babel（トランスパイル）、PostCSS

### 状態管理
- Redux / Zustand（Reactエコシステム）
- Pinia / Vuex（Vueエコシステム）
- Jotai / Recoil（アトミック状態管理）

## バックエンド

### サーバーサイド言語・フレームワーク
- Node.js（Express、Fastify、NestJS）
- Python（Django、FastAPI、Flask）
- Java（Spring Boot、Quarkus）
- Go（Gin、Echo、Fiber）
- Ruby（Ruby on Rails）
- Rust（Actix-web、Axum）
- PHP（Laravel）

### API設計
- REST（リソース指向、HTTPメソッド、ステータスコード）
- GraphQL（スキーマ定義、クエリ、ミューテーション、サブスクリプション）
- gRPC（Protocol Buffers、ストリーミング）
- WebSocket（リアルタイム双方向通信）
- Server-Sent Events（SSE）

### 認証・認可
- セッション認証
- JWT（JSON Web Token）
- OAuth 2.0 / OpenID Connect
- SAML

## マイクロサービス

- サービス分割原則（ドメイン駆動設計、境界コンテキスト）
- サービス間通信（同期 / 非同期、メッセージキュー）
- サービスメッシュ（Istio、Linkerd）
- API ゲートウェイ
- サーキットブレーカーパターン

## コンテナ・オーケストレーション

- Docker（Dockerfile、マルチステージビルド、compose）
- Kubernetes（Pod、Deployment、Service、Ingress）
- Helm（Kubernetesパッケージ管理）
- CI/CD パイプライン（GitHub Actions、GitLab CI）

## サーバーレス

- FaaS（AWS Lambda、Google Cloud Functions、Vercel Edge Functions）
- BaaS（Firebase、Supabase）
- エッジコンピューティング

## パフォーマンス最適化

- CDN（Content Delivery Network）
- キャッシュ戦略（ブラウザ、CDN、サーバー）
- ロードバランシング
- レート制限
- WebAssembly（WASM）
