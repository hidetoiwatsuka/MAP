# AI・機械学習

人工知能と機械学習の主要分野をまとめた参照ファイル群。

## 核となる概念

**データからのパターン学習（最適化による近似）** — 機械学習は「データに最もよく当てはまる関数を探す最適化問題」として定式化できる。ルールを人間が書かずにデータから学ぶ点が本質的な違いであり、何を最小化（損失関数）し・何を汎化するかが設計の核心となる。
