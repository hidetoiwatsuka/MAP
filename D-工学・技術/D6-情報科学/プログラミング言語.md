# プログラミング言語

## プログラミングパラダイム

### 命令型プログラミング
- 手続き型（C・Pascal）：命令の列で処理を記述
- オブジェクト指向（OOP）（Java・C++・Python・Ruby）：カプセル化・継承・ポリモーフィズム
- 状態と副作用を中心とした考え方

### 宣言型プログラミング
- 関数型（Haskell・Erlang・Clojure・F#・Scala）：純粋関数・不変性・ラムダ計算
- 論理型（Prolog）：事実と規則による推論
- SQL等のドメイン特化言語（DSL）

### マルチパラダイム言語
- Python・Scala・Kotlin・Rust・Swift：複数のスタイルをサポート

## 主要プログラミング言語

### 汎用低レベル
- C：ポインタ・手動メモリ管理、OS・組み込みの標準
- C++：C＋OOP＋テンプレートメタプログラミング、高性能計算・ゲームエンジン
- Rust：メモリ安全性（所有権システム）、GCなし、Cの代替候補

### 汎用高レベル
- Python：読みやすさ・豊富なライブラリ、AI/ML・データ分析・Web
- Java：プラットフォーム中立（JVM）・エンタープライズ
- C#：Microsoftエコシステム・ゲーム開発（Unity）
- Go：シンプル・並行処理（goroutine）、クラウドサービス開発
- Kotlin：JVM互換・Androidの公式言語

### 関数型
- Haskell：純粋関数型・型推論・遅延評価
- Erlang/Elixir：アクターモデル・高可用性・リアルタイムシステム

### スクリプト系
- JavaScript/TypeScript：Web フロントエンド・Node.js でバックエンドも
- Ruby：RailsによるWeb開発で有名
- PHP：サーバーサイドWebの老舗

### データサイエンス・科学技術計算
- R（統計解析）・Julia（高性能数値計算）・MATLAB（数値計算・シミュレーション）

## コンパイラ・インタプリタ理論

### コンパイルのフェーズ
1. 字句解析（Lexical Analysis）：ソース→トークン列
2. 構文解析（Syntax Analysis）：トークン列→AST（抽象構文木）
3. 意味解析（Semantic Analysis）：型チェック・スコープ解析
4. 中間コード生成（IR：Intermediate Representation）
5. 最適化（定数畳み込み・ループ最適化・インライン展開）
6. コード生成（ターゲットコード）

### コンパイラ技術
- LL(k)パーサー・LR(k)パーサー（再帰下降・yacc/bison）
- LLVM（Low Level Virtual Machine）：現代的コンパイラ基盤
- JIT（Just-In-Time）コンパイル（JVM・V8 JavaScriptエンジン）

## 型システム

### 型の分類
- 静的型付け（コンパイル時型検査：C/Java/Haskell）vs 動的型付け（実行時：Python/Ruby）
- 強い型付け vs 弱い型付け
- 型推論（Hindley-Milner型推論：Haskell・ML・Rust）

### 型理論
- 多相型（parametric polymorphism：ジェネリクス）
- サブタイプ多相（継承ベースのサブタイプ）
- アドホック多相（オーバーロード・型クラス）
- 依存型（Coq・Agda・Idris）：定理証明プログラミング

## メモリ管理モデル
- 手動メモリ管理（C/C++：malloc/free、new/delete）
- GC（ガベージコレクション）（Java・Go・Python）
- 所有権・借用・生存期間（Rust）：ゼロコスト抽象化

## 並行・並列プログラミング
- スレッドと同期プリミティブ（mutex・condition variable）
- イベントループ・非同期プログラミング（async/await）
- アクターモデル（Erlang・Akka）
- CSP（Communicating Sequential Processes）：Goのchannel
- データ並列性（CUDA・OpenCL・SIMD）
