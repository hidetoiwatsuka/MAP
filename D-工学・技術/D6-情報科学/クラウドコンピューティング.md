# クラウドコンピューティング

## サービスモデル

- IaaS（Infrastructure as a Service）：仮想マシン、ストレージ、ネットワーク
- PaaS（Platform as a Service）：実行環境、DB、ミドルウェア
- SaaS（Software as a Service）：アプリケーション自体を提供
- FaaS / サーバーレス（→ Web技術参照）

## 主要クラウドプロバイダー

### AWS（Amazon Web Services）
- コンピュート（EC2、ECS、EKS、Lambda）
- ストレージ（S3、EBS、EFS、Glacier）
- データベース（RDS、DynamoDB、Redshift、Aurora）
- ネットワーク（VPC、Route53、CloudFront、ELB）
- AI/ML（SageMaker、Bedrock、Rekognition）

### GCP（Google Cloud Platform）
- コンピュート（GCE、GKE、Cloud Run、Cloud Functions）
- ストレージ（Cloud Storage、Persistent Disk）
- データ分析（BigQuery、Pub/Sub、Dataflow、Dataproc）
- AI（Vertex AI、TPU）

### Azure（Microsoft Azure）
- コンピュート（Virtual Machines、AKS、Azure Functions）
- ストレージ（Blob Storage、Azure Files）
- データベース（Azure SQL、Cosmos DB）
- AI（Azure OpenAI Service、Cognitive Services）

## 分散システム設計原則

- CAP定理（一貫性・可用性・分断耐性のトレードオフ）
- BASE（基本的に利用可能、ソフト状態、最終的一貫性）
- ACID vs BASE
- 冪等性とリトライ戦略
- 分散トレーシング（OpenTelemetry、Jaeger）

## インフラストラクチャ as Code（IaC）

- Terraform（マルチクラウド対応）
- AWS CloudFormation
- Pulumi（プログラミング言語によるIaC）
- Ansible（構成管理）

## セキュリティ

- クラウドセキュリティの責任共有モデル
- IAM（Identity and Access Management）
- ゼロトラストアーキテクチャ
- 暗号化（転送中・保存中）
- セキュリティグループ、NACL

## コスト最適化

- リザーブドインスタンス / スポットインスタンス
- 自動スケーリング（水平・垂直）
- コスト可視化・タグ戦略
- FinOps
