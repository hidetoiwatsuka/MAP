# ハードウェア

## コンピュータアーキテクチャの基礎

### フォン・ノイマン型アーキテクチャ
- プログラム内蔵方式（命令とデータを同一メモリに）
- CPU・メモリ・入出力の構成
- 命令サイクル（フェッチ・デコード・実行・ライトバック）

### 命令セットアーキテクチャ（ISA）
- CISC（Complex Instruction Set Computer）：x86/x64
- RISC（Reduced Instruction Set Computer）：ARM・RISC-V・MIPS
- 命令形式（オペコード・オペランド・アドレッシングモード）

## CPU（プロセッサ）

### パイプライン処理
- 5段パイプライン（IF-ID-EX-MEM-WB）
- パイプラインハザード（構造・データ・制御ハザード）
- ハザード回避（フォワーディング・NOP挿入・分岐予測）

### スーパースカラー・アウトオブオーダー実行
- 命令レベル並列性（ILP）の活用
- トマスロアルゴリズム
- レジスタリネーミング・リオーダーバッファ

### マルチコア・マルチスレッド
- SMP（対称型マルチプロセッサ）
- キャッシュコヒーレンスプロトコル（MESI・MOESI）
- HyperThreading（SMT：同時マルチスレッド）

### キャッシュメモリ
- 階層キャッシュ（L1・L2・L3）
- キャッシュの組み合わせ方（直接マッピング・セットアソシアティブ・フルアソシアティブ）
- 置換アルゴリズム（LRU・LFU・FIFO）
- ライトスルー vs ライトバック
- キャッシュフレンドリーなプログラミング

## メモリシステム

### 主記憶（DRAM）
- SDRAM・DDR4・DDR5の原理とバンド幅
- メモリコントローラ・チャネル数
- ECC（Error-Correcting Code）メモリ

### 不揮発性記憶
- NAND フラッシュ（SSD：NVMe・SATA）
- 3D NAND・QLC・TLC・SLC
- NVM（非揮発性メモリ：Optane等）

### メモリ階層
- CPU レジスタ → L1 → L2 → L3 → DRAM → SSD → HDD
- 各レベルの容量・速度・コストのトレードオフ

## 入出力と周辺装置
- バスアーキテクチャ（PCIe・USB・Thunderbolt）
- DMA（ダイレクトメモリアクセス）
- 割り込み駆動I/O vs ポーリング
- ディスクI/O（RAID構成）

## GPU（グラフィクスプロセッサ）
- SMT（ストリーミングマルチプロセッサ）と大規模並列
- CUDA（NVIDIA）・ROCm（AMD）・Metal（Apple）
- GPU によるHPC・AI加速
- NPU（Neural Processing Unit）・TPU（Tensor Processing Unit）

## 量子コンピュータ（概要）
- 量子ビット（qubit）・重ね合わせ・エンタングルメント
- 量子ゲート（Hadamard・CNOT・Pauli）
- 量子誤り訂正
- 現状：NISQ（Noisy Intermediate-Scale Quantum）デバイス
