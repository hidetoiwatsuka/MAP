# データベース

## リレーショナルデータベース（RDB）

### 関係モデルの基礎
- リレーション（テーブル）・属性（列）・タプル（行）
- ドメインと制約（主キー・外部キー・一意制約・NULL制約・CHECK制約）
- 関係代数（選択・射影・結合・和・差・積）

### SQL
- DML（Data Manipulation Language）：SELECT・INSERT・UPDATE・DELETE
- DDL（Data Definition Language）：CREATE・ALTER・DROP
- DCL（Data Control Language）：GRANT・REVOKE
- 結合（INNER JOIN・LEFT/RIGHT/FULL OUTER JOIN・CROSS JOIN）
- 集約関数・GROUP BY・HAVING
- サブクエリ・ウィンドウ関数・CTE（WITH句）
- ビュー・ストアドプロシージャ・トリガー

### 正規化
- 1NF（繰り返しグループの除去）
- 2NF（部分関数従属の除去）
- 3NF（推移的関数従属の除去）
- BCNF（ボイス・コッド正規形）
- 4NF・5NF

### トランザクション
- ACID特性（Atomicity・Consistency・Isolation・Durability）
- 隔離レベル（Read Uncommitted・Read Committed・Repeatable Read・Serializable）
- 並行トランザクションの問題（ダーティリード・ファジーリード・ファントムリード）
- ロック（共有ロック・排他ロック）・デッドロック
- MVCC（Multi-Version Concurrency Control）：PostgreSQL・Oracle

## クエリ最適化

### インデックス
- B+木インデックス（範囲検索・等値検索）
- ハッシュインデックス（等値検索のみ）
- 複合インデックス・部分インデックス・全文検索インデックス
- クラスタードインデックス vs 非クラスタードインデックス

### 実行計画
- クエリオプティマイザ（コストベース）
- EXPLAIN ANALYZE（実行計画の確認）
- ネステッドループ・ハッシュ結合・マージ結合

## 主要RDB
- PostgreSQL（高機能オープンソース・JSON サポート）
- MySQL/MariaDB（Web アプリに広く普及）
- SQLite（組み込み・軽量）
- Oracle Database（エンタープライズ）
- Microsoft SQL Server（Windows エコシステム）

## NoSQL データベース

### ドキュメント型
- MongoDB（BSON ドキュメント・スキーマレス）
- Firestore（Google Cloud）・CouchDB

### キーバリュー型
- Redis（インメモリ・キャッシュ・Pub/Sub・セッション管理）
- Amazon DynamoDB（マネージドサービス・パーティションキー）

### ワイドカラム型（列指向）
- Apache Cassandra（分散・高可用性・最終一貫性）
- HBase（Hadoopエコシステム）
- BigTable（Google）

### グラフデータベース
- Neo4j（Cypher クエリ言語）
- Amazon Neptune

### 時系列データベース
- InfluxDB・TimescaleDB（PostgreSQL拡張）・Prometheus（メトリクス）

## CAP定理と分散データベース
- 一貫性（Consistency）・可用性（Availability）・分断耐性（Partition Tolerance）
- PACELC拡張定理
- BASE（Basically Available・Soft state・Eventually consistent）
- 分散トランザクション（2PC・Sagas パターン）

## データウェアハウス・OLAP
- OLTP（トランザクション処理）vs OLAP（分析処理）
- スタースキーマ・スノーフレークスキーマ
- ETL（Extract・Transform・Load）・ELT
- データレイク・データレイクハウス（Databricks Delta Lake）
- 列指向ストレージ（ClickHouse・Amazon Redshift・Google BigQuery）
