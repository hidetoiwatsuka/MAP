## 入門のための前提知識

このカテゴリに入門するために最低限知っておくべきこと。

| 領域 | 知っておくべきこと |
|------|-------------------|
| コンピュータの基本 | ハードウェア（CPU・メモリ・ストレージ）とソフトウェアの区別、OSの役割、ファイルとフォルダ |
| 2進法 | コンピュータは0と1で動く、ビットとバイト |
| 電気の基本（[B-自然科学](../B-自然科学/README.md)からの依存） | 電圧・電流・抵抗の関係（オームの法則 V=IR の直感）、電池と回路の概念 |
| 物理の基本（[B-自然科学](../B-自然科学/README.md)からの依存） | 力・エネルギー・仕事の関係、熱と温度の区別 |
| 数学（[A-形式科学](../A-形式科学/README.md)からの依存） | 関数、グラフ、基本的な代数、指数（2の10乗＝1024 のような感覚） |
| 材料の直感 | 金属・プラスチック・セラミック・半導体 がそれぞれ違う性質を持つこと |
| プログラミングの概念 | 「命令を順番に書いて機械に実行させる」という考え方（特定言語の知識は不要） |
| インターネットの基本 | ネットワークとは何か、サーバーとクライアント、URLの意味 |

> 工学は「自然法則を利用してモノを作る」分野。物理と数学の基礎がないと設計原理が読めない。情報工学は特に、2進法とコンピュータの構造を知らないと、どの抽象レイヤーの話をしているのか分からなくなる。
