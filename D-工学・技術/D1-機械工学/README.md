# D1 機械工学

物体の運動・変形・エネルギー変換・製造プロセスを扱う工学の基幹分野。

## 核となる概念

**エネルギー変換と力の伝達** — 機械工学はすべて「エネルギーをどう変換し・力をどう伝えるか」に帰着する。熱から仕事へ（熱工学）、流れの力を利用する（流体工学）、変形と破壊の限界（材料力学）——どれもエネルギーと力の観点で統一的に読める。
