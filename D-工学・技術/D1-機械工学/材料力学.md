# 材料力学

## 応力とひずみ

### 基本概念
- 応力（σ = F/A）：単位面積あたりの力（Pa、MPa）
- ひずみ（ε = ΔL/L）：変形量の比
- ヤング率（E = σ/ε）：弾性係数（縦弾性係数）
- フックの法則（弾性域での線形応力-ひずみ関係）

### 応力の種類
- 垂直応力（引張・圧縮）
- せん断応力（τ = V/A）
- 主応力とモールの応力円

### 材料の力学的特性
- 弾性変形と塑性変形
- 降伏応力（σY）・引張強さ（σU）・破断伸び
- 加工硬化・ひずみ硬化
- 疲労（S-N曲線）・クリープ（高温変形）

## 梁の理論

### 曲げ
- 曲げモーメント（M）・せん断力（Q）の分布図
- 断面2次モーメント（I）・断面係数（Z）
- 曲げ応力（σ = My/I）
- たわみ（Euler-Bernoulli梁理論）

### ねじり
- ねじりモーメント（T）
- せん断応力分布（τ = Tr/J）：J：極断面2次モーメント
- ねじり角（θ = TL/GJ）：G：横弾性係数

## 柱・圧力容器
- 細長比（λ = L/k）と座屈（Euler座屈荷重）
- 薄肉圧力容器（フープ応力・軸応力）

## 有限要素法（FEM）
- 節点・要素・形状関数
- 剛性マトリックス・荷重ベクトル
- 応力解析・固有値解析・熱解析
- CAE（Computer-Aided Engineering）との関係

## 破壊力学
- 線形破壊力学（LEFM）
- 応力拡大係数（K）・破壊靱性（KIC）
- き裂進展（疲労き裂：Paris則）
- 損傷許容設計

## 実験的応力解析
- ひずみゲージ（電気的方法）
- 光弾性法（光の等色線・等傾線）
- デジタル画像相関（DIC）
