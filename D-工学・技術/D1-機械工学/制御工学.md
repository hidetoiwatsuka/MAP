# 制御工学

## 制御の基礎概念
- フィードバック制御とフィードフォワード制御
- 開ループ制御と閉ループ制御
- 制御系の構成要素（プラント・センサー・アクチュエーター・コントローラー）

## 古典制御理論

### 伝達関数
- ラプラス変換と伝達関数（G(s) = Y(s)/U(s)）
- ブロック線図の代数（直列・並列・フィードバック）
- 基本要素（比例・積分・微分・1次遅れ・2次遅れ）

### 時間応答
- ステップ応答（立ち上がり時間・オーバーシュート・整定時間）
- 1次・2次系の標準応答
- 過渡特性と定常特性

### 安定性解析
- ルースの安定判別法（特性方程式の係数から判定）
- フルビッツの安定条件
- 根軌跡法（特性根の軌跡）

### 周波数応答
- ボード線図（ゲイン特性・位相特性）
- ナイキスト線図
- 安定余裕（ゲイン余裕・位相余裕）
- ゲイン交差周波数・位相交差周波数

## PID制御
- 比例（P）・積分（I）・微分（D）動作の役割
- PIDパラメータのチューニング（Ziegler-Nichols法）
- ウィンドアップ（積分飽和）と対策

## 現代制御理論

### 状態空間表現
- 状態方程式（ẋ = Ax + Bu）と出力方程式（y = Cx + Du）
- 可制御性と可観測性（カルマンの条件）
- 状態遷移行列

### 状態フィードバック
- 極配置法（所望の閉ループ極を実現する状態フィードバックゲイン）
- 最適制御（LQR：線形二次レギュレータ）
- オブザーバー（ルーエンバーガーオブザーバー）

### カルマンフィルタ
- 最適状態推定（ノイズを考慮した最小二乗推定）
- 予測ステップと更新ステップ
- 拡張カルマンフィルタ（EKF）・アンセンテッドKF（UKF）

## 現代の制御技術

### ロバスト制御
- H∞制御（不確かさに対してのロバスト安定性・性能）
- μ合成

### 非線形制御
- リアプノフ安定論
- フィードバック線形化
- スライディングモード制御

### モデル予測制御（MPC）
- 有限区間の予測モデルに基づく最適化
- 制約付き最適制御
- 化学プロセス・自動運転等への応用

### 適応制御・学習制御
- 自己同調制御（パラメータ推定＋制御器設計）
- 反復学習制御（ILC）
- 強化学習による制御器設計
