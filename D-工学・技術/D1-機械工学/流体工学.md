# 流体工学

## 流体力学の基礎

### 流体の性質
- 密度・比重・粘性係数（動粘度ν = μ/ρ）
- ニュートン流体と非ニュートン流体
- 表面張力・毛管現象
- 圧縮性流体と非圧縮性流体

### 静流体力学
- 静圧（ゲージ圧・絶対圧）
- パスカルの原理
- 浮力（アルキメデスの原理）
- 流体中の平面・曲面への圧力

### 流体の基本方程式
- 連続の式（質量保存：ΔA₁V₁ = A₂V₂）
- ベルヌーイの方程式（p + ½ρv² + ρgh = const）
- ナビエ-ストークス方程式（粘性流体の運動方程式）
- エネルギー方程式

## 管内流れ

### 層流と乱流
- レイノルズ数（Re = ρVD/μ）
- 臨界レイノルズ数（Re ≈ 2300：管内）
- 摩擦損失（Darcy-Weisbachの式）：摩擦係数
- Moody線図

### 損失
- 主損失（管路摩擦）
- 副損失（継手・弁・急拡大・急縮小）
- 全損失と有効頭（effective head）

## 外部流れ

### 物体まわりの流れ
- 境界層（ブラジウスの解：平板上層流境界層）
- 境界層剥離と後流
- 抗力（摩擦抗力＋圧力抗力）・揚力
- ストークス抵抗（Re << 1の球：Cd = 24/Re）

### 翼理論
- 翼型の基本（前縁・後縁・翼弦・最大厚さ・キャンバー）
- NACA翼型
- 揚力発生（循環理論：クッタ-ジューコフスキーの定理）
- ストール（失速）現象

## 流体機械

### ポンプ
- 遠心ポンプ（比速度・HQ特性・効率曲線）
- 軸流ポンプ・混流ポンプ
- 運転点（システム曲線と交点）
- キャビテーション（空洞現象）

### タービン
- 衝動タービン（Pelton水車）
- 反動タービン（Francis水車・Kaplan水車）
- 蒸気タービン・ガスタービン（→熱工学参照）

### 圧縮機・送風機
- 遠心圧縮機・軸流圧縮機・容積型（往復・スクリュー・ルーツ）
- サージング・チョーキング

## 数値流体力学（CFD）
- 支配方程式の離散化（有限差分・有限体積・有限要素）
- 乱流モデル（k-ε model・LES・DNS）
- メッシュ生成と境界条件
- OpenFOAM・ANSYS Fluent等のソフトウェア
