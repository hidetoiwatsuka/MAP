# 熱工学

## 熱力学

### 基本概念
- 系・境界・周囲の定義（閉じた系・開いた系・孤立系）
- 状態量（温度・圧力・体積・エントロピー・エンタルピー）
- 過程（等温・等圧・等積・断熱・多方）

### 熱力学の法則
- 第0法則（熱平衡・温度の概念）
- 第1法則（エネルギー保存：Q = ΔU + W）
- 第2法則（エントロピー増大・不可逆性）
  - カルノーサイクルの効率（η = 1 - TL/TH）
  - クラジウスの不等式（dS ≥ δQ/T）
- 第3法則（絶対零度でエントロピー=0）

### 理想気体の状態式
- PV = nRT
- 気体のモル比熱（Cp、Cv、Cp - Cv = R）
- 比熱比（γ = Cp/Cv）

### 熱サイクル
- カルノーサイクル（理論最大効率）
- オットーサイクル（ガソリンエンジン）
- ディーゼルサイクル
- ブレイトンサイクル（ガスタービン）
- ランキンサイクル（蒸気タービン：発電）
- 冷凍サイクル（冷凍・ヒートポンプ：COP）

## 伝熱（熱移動）

### 熱伝導
- フーリエの法則（q = -kA dT/dx）
- 熱伝導率（k）：材料特性
- 定常・非定常熱伝導
- 複合壁（熱抵抗の直列・並列）

### 対流熱伝達
- 強制対流・自然対流
- ニュートンの冷却則（q = hA(Ts - T∞)）
- 無次元数（レイノルズ数・ヌセルト数・プラントル数・グラスホフ数）
- 熱境界層

### 放射熱伝達
- ステファン-ボルツマンの法則（q = εσT⁴）
- 放射率・黒体・灰色体
- 形態係数（view factor）

### 熱交換器
- 並流型・向流型・クロスフロー型
- LMTD（対数平均温度差）法・NTU-ε法
- フィン（拡大伝熱面）の効率

## 燃焼工学
- 燃焼反応（完全燃焼・不完全燃焼）
- 理論空気量・空気比（λ）
- 発熱量（高位・低位）
- 拡散燃焼・予混合燃焼
- 火炎温度の計算

## 動力工学
- 蒸気発生システム（ボイラー）
- ガスタービンエンジン（コンプレッサー・燃焼器・タービン）
- 複合サイクル発電（CCGT）
- 廃熱回収（コジェネレーション）
