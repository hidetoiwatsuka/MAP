# H. 情報・メディア

知識・情報の生産・流通・受容を研究する学問群。

## サブカテゴリ

- [H1 メディア論](./H1-メディア論.md) — マスメディア・SNS・ジャーナリズム
- [H2 図書館・情報学](./H2-図書館・情報学.md) — 知識組織化・情報検索・アーカイブ
- [H3 コミュニケーション学](./H3-コミュニケーション学.md) — 対人・組織・異文化コミュニケーション

## 深さ・学習方針

- **深さ：第1層**
- **理由：** 情報の流通構造を理解する。フェイクニュースの見抜き方、メディアバイアスの構造、情報の非対称性。判断の入力が汚染されていたら出力も狂う。
- **具体的に何を：** メディアリテラシーの基本原則、情報の信頼性評価フレームワーク、アルゴリズムによる情報選別の仕組み
- **校正：** ニュースソースを複数比較する習慣。

## 入門のための前提知識

このカテゴリに入門するために最低限知っておくべきこと。

| 領域 | 知っておくべきこと |
|------|-------------------|
| メディアの種類 | 新聞・テレビ・ラジオ・インターネット・SNS の区別と特徴 |
| 情報リテラシー | 一次情報と二次情報の区別、情報源の信頼性を疑う姿勢、フェイクニュースの存在 |
| コミュニケーションの基本 | 発信者→メッセージ→受信者 というモデル、「文脈」が解釈を変えること |
| インターネットの基本（[D-工学・技術](../D-工学・技術/README.md)との接点） | Webの仕組み、検索エンジン、アルゴリズムが情報の見え方を変えること |
| 著作権の基本概念 | 他人の作品には権利がある、引用のルール |
| 歴史（[G-人文学](../G-人文学/README.md)との接点） | 印刷革命（グーテンベルク）、マスメディアの発展、インターネットの登場 — メディア史の三大転換点 |
| 言語（[E-人間科学](../E-人間科学/README.md)との接点） | 言語が思考やコミュニケーションの道具であること、多言語環境の存在 |

> メディア論は「情報がどう作られ、伝わり、人を動かすか」を研究する分野。メディアの種類を区別できず、情報の信頼性を問う姿勢がないと、そもそも分析対象が見えない。
