生化学は生命現象を化学の言語で解明します。タンパク質・核酸・糖質・脂質という生体分子とその代謝・シグナル伝達を研究します。

## 核となる概念

**酵素による反応の制御** — 生体内の化学反応は勝手には起きない。酵素がいつ・どこで・どのくらい反応を進めるかを制御している。代謝経路もシグナル伝達も、結局「どの酵素がどう調節されるか」の話になる。酵素の活性化・阻害・フィードバック制御を押さえれば、代謝異常疾患や薬の作用機序が一気に見通せる。
