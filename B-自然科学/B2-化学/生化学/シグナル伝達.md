# シグナル伝達

シグナル伝達は細胞外の信号（ホルモン・神経伝達物質・成長因子）を細胞内の応答に変換するプロセスです。

## 受容体の種類

- 細胞表面受容体
  - Gタンパク質共役受容体（GPCR）：最大の受容体スーパーファミリー
  - 受容体型チロシンキナーゼ（RTK）：EGF受容体・インスリン受容体
  - イオンチャネル型受容体（リガンド依存性）
  - サイトカイン受容体（JAK-STAT経路）
- 核内受容体（ステロイドホルモン・甲状腺ホルモン）

## 主要なシグナル経路

### cAMPシグナル経路
- Gsタンパク質 → アデニル酸シクラーゼ → cAMP産生 → PKA活性化

### IPₓ/DGシグナル経路
- Gqタンパク質 → PLCβ → IP₃（Ca²⁺動員）+ DAG（PKC活性化）

### MAPキナーゼ経路（ERK経路）
- 成長因子 → RTK → Ras → Raf → MEK → ERK → 遺伝子発現

### PI3K-Akt-mTOR経路
- インスリン・成長因子 → RTK → PI3K → PIP₃ → PDK1 → Akt → mTOR

### Wnt・Notch・Hedgehog経路
- 発生・細胞増殖・幹細胞の制御

## セカンドメッセンジャー

- cAMP（アデノシン3',5'-環状一リン酸）
- cGMP
- IP₃（イノシトール1,4,5-三リン酸）
- DAG（ジアシルグリセロール）
- Ca²⁺（カルモジュリン・PKC活性化）
