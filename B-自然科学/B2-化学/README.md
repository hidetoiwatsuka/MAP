# B2. 化学

化学は物質の組成・構造・性質・変化を研究します。物理と生物の橋渡し役として、医薬品・材料・エネルギーの開発に直結します。

## 核となる概念

**電子の移動・共有による物質変換** — 化学反応はすべて、電子の授受（酸化還元）または共有（共有結合の形成・切断）として記述できる。「どの電子がどこに行くか」を追うことで、有機反応機構も触媒も電池も統一的に理解できる。
