# B. 自然科学

自然科学は自然界の現象を観察・実験・理論によって研究する学問群です。形式科学（数学・論理）を道具として使い、物理・化学・地球・生物を探求します。

## 核となる概念

**自然法則の定量的記述と実験による検証** — 自然科学の本質は「観察・実験→仮説→予測→検証」のサイクル。現象を数式で記述し、その予測が実験で確かめられたとき、理論は信頼を獲得する。法則は覚えるものでなく、「なぜその式になるか」を問うことで理解が深まる。

## 深さ・学習方針

- **深さ：第2層（生物は第3層寄り）**
- **理由：** 現実世界のルールブック。工学もゲノムもロボティクスも、ここが土台。医学の基礎でもある。
- **具体的に何を：** 力学・熱力学・電磁気の基本原理、化学結合と反応速度の概念、分子生物学のセントラルドグマ、進化の仕組み
- **校正：** 物理シミュレーションを一つ書く。化学反応の帰結を予測してから確認する。

## 入門のための前提知識

このカテゴリに入門するために最低限知っておくべきこと。

| 領域 | 知っておくべきこと |
|------|-------------------|
| 物質の基本構造 | 原子→分子という階層、元素とは何か、周期表の存在（暗記不要、構造を知ること） |
| エネルギーの直感 | エネルギーは形を変える（運動→熱→光など）、エネルギー保存の法則の概念 |
| 力と運動 | 力を加えると物は加速する（ニュートンの直感）、重力の存在、速度と加速度の区別 |
| 単位系 | メートル・キログラム・秒（SI単位）、単位の換算ができること |
| 科学的方法 | 仮説→実験→検証というサイクル、「再現性」の意味、相関≠因果 |
| 数学（[A-形式科学](../A-形式科学/README.md)からの依存） | 比例・反比例、グラフの読み書き、基本的な代数（公式に数値を代入する） |
| 地球の基本 | 地球は球体で自転・公転している、大気と海洋がある、地殻の存在 |
| 生物の基本 | 細胞が生物の基本単位、DNA が遺伝情報を持つ（詳細不要）、生物は進化する |

> 自然科学は「自然界の仕組みを定量的に記述する」分野。単位・測定・グラフ・基本的な代数ができないと、法則の式を読めない。物質の階層構造（原子→分子→細胞→組織→…）の感覚がないと、どの分野が何のスケールを扱っているかが分からない。
