# B. 自然科学

自然科学は自然界の現象を観察・実験・理論によって研究する学問群です。形式科学（数学・論理）を道具として使い、物理・化学・地球・生物を探求します。

## サブカテゴリ

- [B2. 化学](B2-化学/README.md) — 物質の組成・構造・変化の研究
- [B3. 地球科学](B3-地球科学/README.md) — 地球の構造・大気・海洋・気候
- [B4. 生物学](B4-生物学/README.md) — 生命現象の包括的研究
