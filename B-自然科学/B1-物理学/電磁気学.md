# 電磁気学

電磁気学は電気と磁気の現象、そしてそれらの統一理論を扱います。マクスウェル方程式が理論の中核です。

## 静電気学

- クーロン力（F = kq₁q₂/r²）
- 電場（E = F/q）
- ガウスの法則（∇·E = ρ/ε₀）
- 電位・電位差（電圧）
- 電気双極子
- 静電容量・コンデンサ

## 静磁気学

- ビオ＝サバールの法則（電流が作る磁場）
- アンペールの法則（∇×B = μ₀J）
- ローレンツ力（F = q(v×B)）
- 磁気双極子・磁気モーメント

## マクスウェル方程式

- ガウスの法則（電気）：∇·E = ρ/ε₀
- ガウスの法則（磁気）：∇·B = 0
- ファラデーの電磁誘導：∇×E = -∂B/∂t
- アンペール＝マクスウェルの法則：∇×B = μ₀J + μ₀ε₀∂E/∂t
- 変位電流の導入によって電磁波の存在を予測

## 電磁波

- 電磁波の導出（波動方程式）
- 光速 c = 1/√(μ₀ε₀)
- 電磁スペクトル（ラジオ波・マイクロ波・赤外・可視光・紫外・X線・γ線）
- ポインティングベクトル（エネルギー流束）

## 光学

### 幾何光学
- 反射・屈折（スネルの法則）
- レンズ・ミラーの公式
- 光学系（望遠鏡・顕微鏡）

### 波動光学
- ヤングの干渉実験（二重スリット）
- 回折（ホイヘンスの原理、フラウンホーファー回折）
- 偏光（マリュスの法則）

### 量子光学
- 光の粒子性（光電効果・コンプトン散乱）
- 光子・フォトン
- レーザー（誘導放出・光共振器）
