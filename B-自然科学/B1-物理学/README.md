# B1. 物理学

物理学は自然界の最も基本的な法則を研究します。古典力学から量子力学・相対性理論まで、現代科学の中核です。

## 核となる概念

**対称性と保存則** — 自然には「何かが変わっても変わらないもの（保存量）」が存在する。エネルギー・運動量・角運動量の保存則は、ノーターの定理が示すように、それぞれ時間・空間・回転の対称性から導かれる。物理の法則を覚えるより「この系には何の対称性があるか」と問う方が深い理解につながる。
