# C2 臨床内科

内科系各専門領域の疾患について、診断・治療の概要をまとめた参照ファイル群。

## 核となる概念

**臨床推論（症候から病態へ）** — 患者の訴え・所見・検査値から「どこが・なぜ壊れているか」を絞り込む推論プロセスが内科の核心。基礎医学の知識を「症候の説明」に変換できるかが、暗記学習と臨床的理解の分岐点になる。
