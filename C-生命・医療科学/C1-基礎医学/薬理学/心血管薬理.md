# 心血管薬理

## 抗不整脈薬（Vaughan Williams分類）

### Class I：Naチャネル遮断薬
- Class Ia（キニジン、プロカインアミド、ジソピラミド）：活動電位延長
- Class Ib（リドカイン、メキシレチン）：活動電位短縮、心室性不整脈
- Class Ic（フレカイニド、プロパフェノン）：強力なNa遮断、上室性不整脈

### Class II：β遮断薬
- プロプラノロール、メトプロロール、エスモロール
- 適応：上室性頻脈、心房細動のレートコントロール

### Class III：Kチャネル遮断薬（活動電位延長）
- アミオダロン（多チャネル遮断、広域スペクトル）
- ソタロール（β遮断作用も併せ持つ）
- 適応：心室性不整脈、心房細動の洞調律維持

### Class IV：Caチャネル遮断薬
- ベラパミル、ジルチアゼム
- 適応：上室性頻脈、心房細動のレートコントロール

### その他の抗不整脈薬
- アデノシン（発作性上室性頻拍の即時停止）
- ジゴキシン（心房細動のレートコントロール、心不全）
- アトロピン（除脈）

## 降圧薬

### ACE阻害薬
- エナラプリル、カプトプリル、リシノプリル
- 機序：アンジオテンシンII産生抑制、ブラジキニン分解抑制
- 適応：高血圧、心不全、糖尿病性腎症
- 副作用：空咳（ブラジキニン蓄積）、血管神経性浮腫、高カリウム血症

### ARB（アンジオテンシンII受容体拮抗薬）
- ロサルタン、カンデサルタン、オルメサルタン
- 機序：AT1受容体選択的遮断
- 特徴：ACE阻害薬と同様の効果、空咳なし

### Ca拮抗薬
- ジヒドロピリジン系（アムロジピン、ニフェジピン）：末梢血管拡張優位
- 非ジヒドロピリジン系（ベラパミル、ジルチアゼム）：心臓抑制作用も
- 副作用：顔面紅潮、頭痛、下腿浮腫、歯肉増生

### 利尿薬
- サイアザイド系（ヒドロクロロチアジド）：中等度降圧、低K血症
- ループ利尿薬（フロセミド）：強力利尿、低K血症
- K保持性利尿薬（スピロノラクトン）：アルドステロン拮抗、高K血症

### 直接血管拡張薬
- ヒドララジン（妊娠高血圧、心不全）
- ニトロプルシドナトリウム（高血圧クリーゼ）

## 心不全治療薬

### 神経体液因子阻害薬
- ACE阻害薬/ARB（RAAS抑制）
- β遮断薬（交感神経系抑制、心臓リモデリング阻害）
- ARNI（サクビトリル/バルサルタン：ネプリライシン阻害＋ARB）
- ミネラルコルチコイド受容体拮抗薬（エプレレノン、スピロノラクトン）
- SGLT2阻害薬（エンパグリフロジン、ダパグリフロジン）

### 陽性変力薬

- ドパミン・ドブタミン（急性心不全）
- ホスホジエステラーゼ阻害薬（ミルリノン：ICUでの急性心不全）

## 抗狭心症薬

### 硝酸薬
- ニトログリセリン（舌下・貼付）、硝酸イソソルビド
- 機序：NO放出→cGMP増加→血管平滑筋弛緩（静脈拡張優位）
- 副作用：頭痛、低血圧、タキフィラキシー（耐性）

### β遮断薬
- 心拍数・心収縮力低下→心酸素需要減少

### Ca拮抗薬
- 冠攣縮性狭心症にも有効

## 脂質異常症治療薬
- スタチン（HMG-CoA還元酵素阻害：ロスバスタチン、アトルバスタチン）
- エゼチミブ（コレステロール吸収阻害）
- PCSK9阻害薬（エボロクマブ：LDL受容体増加）
- フィブラート（PPARα活性化、TG低下・HDL上昇）
- ニコチン酸（HDL上昇）

## 抗血栓薬

### 抗血小板薬
- アスピリン（COX阻害、TXA2産生抑制）
- クロピドグレル・プラスグレル（ADP受容体P2Y12阻害）
- チカグレロール（P2Y12可逆的阻害）
- GPIIb/IIIa阻害薬（アブシキシマブ）

### 抗凝固薬
- ヘパリン（AT III活性化→Xa・トロンビン阻害）、LMWH
- ワルファリン（ビタミンK拮抗薬：II、VII、IX、X因子阻害）
- 直接経口抗凝固薬（DOAC）：リバーロキサバン（Xa阻害）、ダビガトラン（トロンビン阻害）

### 血栓溶解薬
- tPA（アルテプラーゼ）、ウロキナーゼ
- 適応：急性心筋梗塞、脳梗塞、肺血栓塞栓症
