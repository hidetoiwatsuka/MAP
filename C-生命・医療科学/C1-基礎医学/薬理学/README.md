# 薬理学

薬物と生体の相互作用を研究する学問。薬物動態（体が薬をどう処理するか）と薬力学（薬が体にどう作用するか）の二本柱からなる。

## 核となる概念

**受容体とリガンドの相互作用** — 薬は結局、特定の分子標的に結合して生体反応を変える。用量-反応関係、アゴニスト/アンタゴニスト——すべてこの結合の話に帰着する。「どの受容体に・どう結合し・どんな応答を引き起こすか」を軸にすると、無数の薬が体系的に理解できる。
