# C1. 基礎医学

基礎医学は臨床医学の科学的基盤となる学問群です。

[Medical Terminology](../../00_inbox/Medical%20Terminology.md)

## 核となる概念

**分子から個体までの因果連鎖** — 基礎医学の各分野は「分子（生化学）→細胞（組織学）→臓器（解剖学・生理学）→個体（病理学）」という階層を貫く因果連鎖を共有している。個別分野の知識も、この連鎖の中のどの段階を担うかを意識すると体系的に位置づけられる。
