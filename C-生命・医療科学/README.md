## 深さ・学習方針

- **深さ：第3層（本業）**
- **理由：** キャリアの実装先。
- **具体的に何を：** 解剖・生理・病理・薬理の全体系。臨床推論。カテーテル技術。研究方法論。
- **校正：** 臨床実習、研究、試験。6年間＋研修で強制的に積まれる。

## 入門のための前提知識

このカテゴリに入門するために最低限知っておくべきこと。

| 領域 | 知っておくべきこと |
|------|-------------------|
| 人体の大枠 | 主要な臓器の名前と大まかな位置（心臓・肺・肝臓・腎臓・脳・胃・腸）、それぞれが何をしているかの一行説明 |
| 細胞の基本 | 細胞膜・核・ミトコンドリアの存在、細胞分裂が起きること |
| 化学の基礎（[B-自然科学](../B-自然科学/README.md)からの依存） | 水溶液・pH（酸性/アルカリ性）、タンパク質・脂質・糖質・核酸が生体の主要分子であること |
| 生物学の基礎（[B-自然科学](../B-自然科学/README.md)からの依存） | 遺伝の仕組み（DNA→RNA→タンパク質の流れの存在）、ホメオスタシス（体内環境を一定に保つ仕組み）の概念 |
| 解剖学的方位 | 前/後、上/下、内側/外側、左右 の方向用語 |
| 心理学の前提 | 「心」も科学的に研究できるという認識、行動と認知の区別 |
| 統計の初歩（[A-形式科学](../A-形式科学/README.md)からの依存） | 平均・中央値、「統計的に有意」がざっくり何を意味するか |

> 医学の教科書は「細胞とは何か」から説明しない。化学と生物学の基礎語彙（タンパク質、受容体、イオン、膜電位など）を前提として話が進む。臓器の名前と位置も既知として扱われる。
