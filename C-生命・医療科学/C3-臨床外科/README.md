# C3 臨床外科

外科系各専門領域の疾患・手術について概要をまとめた参照ファイル群。

## 核となる概念

**解剖学的理解に基づく侵襲と修復** — 外科は「切る・縛る・繋ぐ・取る」という物理的介入によって疾患を治療する。どこをどう触れば何が起き、何を守らなければならないか——すべては解剖学の三次元的理解と、侵襲に対する生体の修復反応の理解に帰着する。
