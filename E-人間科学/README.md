## 入門のための前提知識

このカテゴリに入門するために最低限知っておくべきこと。

| 領域 | 知っておくべきこと |
|------|-------------------|
| 社会の基本構造 | 家族・学校・会社・国家 という社会単位の階層、「制度」とは何か |
| 文化の概念 | 人間の行動は生物的だけでなく文化的に規定される、文化は地域・時代で異なる |
| 言語の基本 | 世界には多数の言語がある、文法は言語ごとに違う、「母語」の概念 |
| 歴史の基本的時間軸 | 古代→中世→近代→現代 という大まかな区分（西洋史・日本史とも） |
| 地理の基本（[K-地理・地政学](../K-地理・地政学/README.md)との接点） | 世界の主要な地域区分（ヨーロッパ、アジア、アフリカ等）、主要国の位置 |
| 科学的方法（[B-自然科学](../B-自然科学/README.md)からの依存） | 仮説検証、データ収集、観察と実験の違い |
| 心理の基本 | 人間には認知バイアスがある、記憶は完全ではない、動機づけの存在 |
| 統計リテラシー（[A-形式科学](../A-形式科学/README.md)からの依存） | サンプルと母集団、平均と分散、相関と因果の区別 |

> 人間科学は「人間を社会的・文化的・認知的存在として研究する」分野。「社会とは何か」「文化とは何か」という出発点の概念がないと、何を研究しているのかが分からない。また、統計と科学的方法論は、社会科学の論文を読む最低条件。
