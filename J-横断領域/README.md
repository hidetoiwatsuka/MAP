# J. 横断領域

複数の学問分野をまたぎ、共通の枠組みや方法論を提供する知識領域。

## サブカテゴリ

- [J1 システム思考](./J1-システム思考.md) — フィードバック・創発・複雑系
- [J2 デザイン思考](./J2-デザイン思考.md) — 共感・プロトタイプ・反復
- [J3 データサイエンス](./J3-データサイエンス.md) — データ収集・分析・因果推論・可視化
- [J4 生命倫理・技術倫理](./J4-生命倫理・技術倫理.md) — インフォームドコンセント・AI倫理・遺伝子編集
- [J5 環境科学・持続可能性](./J5-環境科学・持続可能性.md) — 気候変動・生物多様性・循環経済

## 入門のための前提知識

このカテゴリに入門するために最低限知っておくべきこと。

| 領域 | 知っておくべきこと |
|------|-------------------|
| システム思考の入口 | 「全体は部分の総和以上」の直感、フィードバックループ（悪循環・好循環）の概念 |
| デザインの基本 | デザイン＝見た目だけでなく「問題解決の設計」、ユーザー視点の重要性 |
| データの基本（[A-形式科学](../A-形式科学/README.md)からの依存） | データとは何か、定量データと定性データの区別、グラフの種類（棒・折れ線・円・散布図） |
| 統計（[A-形式科学](../A-形式科学/README.md)からの依存） | 平均・分散・相関の意味、サンプルサイズの重要性 |
| 倫理の基本（[G-人文学](../G-人文学/README.md)との接点） | 「正しい」とは何か — 功利主義（結果重視）と義務論（原則重視）の区別があること |
| 複数分野の基礎知識 | J は横断領域なので、A〜Hの少なくとも2〜3カテゴリの基礎が必要 |

> 横断領域は「複数分野を繋ぐ思考法」を扱う。1つの分野にも入門してない状態では、「何と何を繋ぐのか」が分からない。最低でも2〜3カテゴリの基礎を持ったうえで入るのが現実的。
