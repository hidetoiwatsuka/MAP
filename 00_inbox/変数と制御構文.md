## 変数とは
メモリのスペースを先に確保しておいて後から変更できるもののこと

```c
#include <stdio.h>

int main (void){

	int value;
	value = 10;
	printf("%d" ,value);
	return 0;

}
```
  

|要素|意味|
|---|---|
|`int`|型の指定（4バイトの整数を扱うと宣言）|
|`value`|変数名（プログラマが自由に決める名前）|
|`int value`|宣言：「`int` サイズのメモリを確保して `value` という名前をつける」|
|`=`|代入演算子：右辺の値を左辺の変数に入れる|
|`int value = 10;`|宣言 + 初期化：メモリ確保して `value` と名付け、`10` を入れる|

- プログラムはメモリに保存される
- メモリにプログラムを読み込むことで処理を行っている
- エンジニアはメモリに入ったデータを扱う仕事
- 変数はこのメモリのスペースを事前に確保する

- A = adress ここにデータを保存する
- Aピンが左からonとoff、これが二進数の0と1を表す
- A1っ本0と1を表せるのでこの10っポンのピンで2の10乗の1024通りある
- intは4bit分確保するのでこのメモリを四本確保することになる

### 変数を確保した時、メモリのアドレスはどう確保してる？

|型|サイズ|用途|
|---|---|---|
|`char`|1バイト|文字・小さい整数|
|`int`|4バイト|整数（一番よく使う）|
|`float`|4バイト|小数|
|`double`|8バイト|小数（精度高い）|
