## 中核命題

脳は感覚を原材料として関数を構築し、構築された関数の総体が脳内世界を形成する。思考とはこの脳内世界の上で操作を行うことであり、操作には処理コストがかかる。関数化済みの要素はコストゼロで走り、関数化されていない要素が脳の有限な処理容量を消費する。感覚語は具体的感覚の離散的集合ではなく、すべてが溶け合った統合的近似値として保存される。情報の最終的な現れは常に感覚であり、感覚化されない操作は計算であって理解ではない。

---

## 第一章：感覚 — 情報の原材料

人間が直接アクセスできる情報は、すべて感覚として経験されたものである。

```
┌──────────────────────────────────────────────┐
│               感 覚                          │
│         情報の原材料。具体的、一回的            │
│                                              │
│   外的感覚        内的感覚      感覚間の繋がり  │
│  （視・聴・触・   （感情・身体   （AのあとにBが  │
│   味・嗅）        感覚・直感）    来た、など）   │
└──────────────────────────────────────────────┘
```

外的五感、内的感覚（感情・身体感覚・直感）、そして感覚同士の時間的・因果的繋がりの体験。これらが脳に保存される情報の原材料であり、すべての上位構造の出発点である。

実際に観測された個々の感覚は、すべて一回的で具体的な経験であり、それ自体は固定されている。

## 第二章：関数の構築 — 学習

### 初期状態

生まれた時、脳には有用な関数がほぼ存在しない。あるのは煩悩——充足の手段を持たない根源的な欲求のみ。

$$\text{欲求（入力）} \xrightarrow{f = \text{???}} \text{満足（出力）}$$

脳は入力と望ましい出力が定義されているが、処理が空の関数である。学習の全プロジェクトは、この処理の箱を埋めること。

### 構築メカニズム

脳は試行錯誤のサイクルを通じて関数を構築する。

$$\text{入力} \xrightarrow{f_{\text{現在}}} \text{出力} \xrightarrow{\text{現実と比較}} \text{誤差信号} \xrightarrow{\text{更新}} f_{\text{改善}}$$

各サイクルが内部関数を精錬する。予想より良い結果→関数を強化。予想より悪い→関数を弱化。予想通り→関数は安定、その関数の学習は完了。これが「驚きの漸進的減少」としての学習の内的体験である。

煩悩は学習の障害ではなく**エンジン**である。欲求なしには入力を処理する動機がなく、不快なしには誤差信号がない。

### 関数獲得の段階

|Level|名称|内容|対応する認知構造|
|---|---|---|---|
|1|刺激-反応|直接マッピング。熱い→手を引く|感覚の直接的連結|
|2|パターン認識|規則性の抽出。「落とすと落ちる」|感覚語の形成|
|3|モデル構築|新状況の予測。「この角度で投げれば…」|感覚語の精錬|
|4|抽象化|領域横断のパターン抽出|**関係構造の抽出**|
|5|関数の合成|既存関数を新しい構成に組み立てる|関係構造の合成・循環|

Level 1-3は感覚と関数が不可分——すべて感覚に接地したまま構築される。Level 4で転換が起こり、感覚語から関係構造が抽出される。Level 5は関係構造同士の操作と循環的生成。

### 外的関数と内的関数

- **外的関数**：現実を支配する法則。重力、熱力学、社会的力学。観察者から独立に存在
- **内的関数**：脳による外的関数の近似。常に不完全、時に誤り、継続的に精錬される

$$f_{\text{内的}} \xrightarrow{\text{学習}} f_{\text{内的}} \approx f_{\text{外的}}$$

内的関数が現実と一致しない時、二つの結果がありうる。内的関数の更新（通常の学習）、または外的関数についての予想外の発見（科学的発見）。

## 第三章：感覚語 — 感覚の統合的近似値

### 感覚語の構造

```
   無数の具体的感覚
    ││││││││
    ▼▼▼▼▼▼▼▼
  ┌──────────────────────────────────┐
  │          統 合 的 圧 縮            │
  │                                  │
  │ 個々の感覚が離散的に保存されるのでは │
  │ なく、すべてが溶け合って一つの       │
  │ 近似的プロトタイプになる            │
  │                                  │
  │ 鮮明な領域 → 定概念               │
  │ ぼやけた領域 → 変概念              │
  └────────────┬─────────────────────┘
               ▼
  ┌───────────────────────────────────────┐
  │  感覚語 ＝ 記号 ＋ 統合的近似値         │
  │           （＋ 強烈な個別記憶）         │
  └───────────────────────────────────────┘
```

感覚語は二つの要素からなる複合体である。

- **記号**：区別可能な音や形の配列。それ自体には意味がない。統合的近似値へのポインタ
- **統合的近似値**：その記号が指し示す、具体的感覚が溶け合った一つのプロトタイプ

記号に統合的近似値を対応させる行為が「意味を持たせる」ことの正体である。

### 保存形式 — 離散的集合ではなく統合的近似値

脳は具体的感覚を個別に保存しているのではない。「犬」と聞いた時に立ち上がるのは、特定の犬の記憶ではなく、**すべての犬の経験が溶け合ったぼんやりとした一つの像**である。輪郭はあるが細部がない。四本脚で、毛があって、ある程度の大きさで——しかし色も大きさも犬種も、特定の値を取らず曖昧なまま浮かぶ。

定概念・変概念という構造は維持されるが、その実体は個々の経験の離散的集合ではなく、すべてが溶け合った一つの近似的プロトタイプとして保存されている。

### 定概念と変概念 — 鮮明さとぼやけ

$$\text{感覚語} = \underbrace{\text{鮮明な領域}}_{\text{定概念}} + \underbrace{\text{ぼやけた領域}}_{\text{変概念}}$$

- **定概念**：統合的近似値の中で**鮮明な領域**。集合内の感覚に共通する要素が、近似値の中ではっきりと浮かび上がっている部分
- **変概念**：統合的近似値の中で**ぼやけた領域**。個々の感覚ごとに異なる要素が、特定の値を取らず曖昧なまま存在している部分

「犬」の近似値において、「四本脚」「毛がある」は鮮明に浮かぶ（定概念）。「色」「大きさ」はぼやけている（変概念）。

同じ感覚的要素が、参照する集合の抽象度によって鮮明にもぼやけにもなる（二重性）。

### 二重保存 — 近似値と個別記憶

通常の感覚経験は統合的近似値に溶け込むが、感情的強度が閾値を超えた経験は溶け込まず**個別に保存**される。

```
  「犬」と聞いた時
    │
    ├─ 通常 → ぼんやりした犬の統合的近似値が浮かぶ
    │
    └─ 強烈な記憶がある場合 → その特定の犬が鮮明に浮かぶ
       （例：子供の頃に噛まれた犬）
```

- **統合的近似値**：通常の感覚経験が溶け合った一つのプロトタイプ。ぼんやりしている
- **個別記憶**：感情的強度が閾値を超えた経験。鮮明なまま保存される

### 連想の仕組み — 近似マッチング

現実で感覚を受け取った時、それが保存された統合的近似値に**近い**と、感覚語が発火する。完全一致ではなく近似マッチング。

$$\text{新しい感覚入力} \xrightarrow{\text{近似マッチング}} \text{統合的近似値} \xrightarrow{\text{連想}} \text{感覚語の発火}$$

見たことのない犬種でも「犬だ」とわかるのは、近似値との距離が十分に近いから。逆に、近似値からの距離が大きすぎると認識できない——初見の生物が「何だかわからない」状態。

### 感覚語の本質的性質

**自立性**——どこまで抽象化しても、定概念（鮮明な領域）と変概念（ぼやけた領域）を持つ統合的近似値であり続ける。展開すれば必ず感覚に着地する。これが関係構造との本質的な差異。

### 感覚語の三類型

|類型|圧縮対象|例|
|---|---|---|
|外的感覚の圧縮|外界の感覚パターン|無数の「赤い」経験 → 「赤」の近似値|
|内的感覚の圧縮|感情・身体感覚|無数の「悲しい」経験 → 「悲しみ」の近似値|
|感覚間の繋がりの圧縮|因果・順序・共起|「火→痛い」の反復 → 「火は熱い」の近似値|

第三の類型が反復的に経験されることで、次の層——関係構造——が抽出される。

## 第四章：関係構造 — 感覚語から抽出された抽象的鋳型

### 抽出過程

```
  感覚語A ──→ 感覚語B    感覚語C ──→ 感覚語D
  感覚語E ──→ 感覚語F    感覚語G ──→ 感覚語H
       │            │           │           │
       └──────┬─────┘           └─────┬─────┘
              │ 同一パターンの反復          │
              └────────────┬───────────────┘
                           ▼
                 ┌───────────────────┐
                 │   関係構造         │
                 │  （ ）──→（ ）    │
                 │   空のスロット     │
                 └───────────────────┘
```

感覚語間の接続パターンが異なる領域で反復されると、パターンそのものが具体的感覚から切り離されて保存される。これが関係構造——空のスロットを持つ抽象的鋳型である。Learning文書のLevel 4に対応する。

$$\text{感覚語間の反復的パターン} \xrightarrow{\text{抽出}} \text{関係構造（抽象的鋳型）}$$

### 本質的性質

**非自立性・感覚語依存**——関係構造はそれ自体としては感覚的に体験できない。感覚語を代入されて初めて感覚化される。

$$f_{\text{関係構造}}(x) \quad \text{where } x = \text{感覚語}$$

同じ $f$ に異なる感覚語を代入するたびに「わかる」が成立するが、中身は $x$ によって変動する。$f$ 自体は抽象にとどまる。関係構造は情報の独立形式ではなく、感覚語に寄生する操作形式である。

## 第五章：計算と理解

```
┌──────────────────────────────────────────────────┐
│                                                  │
│   計算 ＝ 関係構造の操作（感覚語の代入なし）        │
│                                                  │
│   関係構造同士を接続・変形する。                    │
│   操作の正否についてフィードバック信号が出る         │
│  （「通る」「矛盾する」）。                         │
│   しかしこのフィードバックは五感的感覚ではない。     │
│   正しいかどうかの信号を受けているだけで、           │
│   感覚的に落とし込んでいるわけではない。             │
│                                                  │
│   → 理解ではない                                 │
│                                                  │
├──────────────────────────────────────────────────┤
│                                                  │
│   理解 ＝ 感覚的な「わかる」の成立                  │
│                                                  │
│   何らかの経路を通じて、五感的な感覚として           │
│   体験される状態。体に染み付く感覚を伴う。           │
│                                                  │
│   → 四つの経路がある（次節）                       │
│                                                  │
└──────────────────────────────────────────────────┘
```

形式的な記号操作の正確さと、感覚への接地としての理解は、別の能力である。前者だけを持つ状態が計算であり、両者を持つ状態が理解である。

### 暗記の位置づけ

暗記は記号を記号のまま保存する操作。ポインタだけを保存し、その先の統合的近似値に接続しない。感覚への展開も関係構造への代入も伴わない。これが「言葉は知っているが理解していない」状態。

## 第六章：理解の四経路

```
                    ┌─────────────┐
                    │  感覚的な    │
                    │ 「わかる」   │
                    └──────┬──────┘
           ┌───────┬───────┼───────┬────────┐
           ▼       ▼       ▼       ▼        │
        経路1    経路2    経路3    経路4      │
        直接     代入     借用    論理的      │
        展開                      生成       │
                                    │        │
                                    └────────┘
                                     循環構造
```

### 経路1：直接展開

感覚語の統合的近似値をそのまま感覚として立ち上げる。最も単純な理解。

$$\text{「赤」} \xrightarrow{\text{展開}} \text{赤の統合的近似値が感覚として浮かぶ}$$

近似値であるため、展開された感覚は具体的な一回の経験ではなく、ぼんやりとした代表的感覚として体験される。強烈な個別記憶が存在する場合は、それが鮮明に浮かぶこともある。

### 経路2：代入

関係構造に感覚語を流し込み、構造を通じて感覚的に体験する。

$$\text{関係構造} + \text{感覚語の代入} \xrightarrow{} \text{感覚的な「わかる」}$$

### 経路3：借用

直接的な感覚を持たない概念に対して、他の感覚語から感覚的要素を抽出し移植する。比喩・アナロジーの本質。

$$\text{未知の概念} \xleftarrow{\text{感覚的要素の抽出・移植}} \text{既知の感覚語}$$

借用による理解は**近似的**である。借りた感覚は対象そのものの感覚ではないため、常に「だいたいこういう感じ」という限界を伴う。

### 経路4：論理的生成

関係構造を論理的に展開し、脳内で仮の感覚をシミュレーションする。十分な時間滞在すれば、仮の感覚が感覚として定着する。

$$\text{関係構造} \xrightarrow{\text{論理的展開}} \text{脳内シミュレーション} \xrightarrow{\text{反復・滞在}} \text{感覚として定着}$$

借用と論理的生成は組み合わさることが多い。既存の感覚要素を借りつつ、関係構造に基づいてそれを変形・再構成し、未経験の感覚を生成する。

### 理解不能の条件

|条件|状態|
|---|---|
|統合的近似値が保存されていない|感覚語の展開先がない。空の記号|
|関係構造に代入する感覚語がない|鋳型は空のまま|
|借用できる感覚的要素がない|近似マッチングできる既知の感覚語がない|
|論理的生成の解像度・滞在時間が不足|シミュレーションが感覚として定着しない|

## 第七章：脳内世界と処理コスト

### 脳内世界

脳内には、今まで蓄積してきた感覚的関数が無数に存在している。重力、光の反射、物体の衝突、液体の挙動、人間の感情パターン——これらは普段意識されないが、常時バックグラウンドで稼働している。この関数の総体が**脳内世界**を形成している。

```
┌─────────────────────────────────────────────────────────┐
│                    脳内世界                               │
│          蓄積された感覚的関数の総体                         │
│                                                         │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐          │
│  │ 重力  │ │ 光   │ │ 空間  │ │ 因果  │ │ 感情  │ …       │
│  │ 関数  │ │ 関数  │ │ 関数  │ │ 関数  │ │ 関数  │         │
│  └──────┘ └──────┘ └──────┘ └──────┘ └──────┘          │
│   コスト0   コスト0   コスト0   コスト0   コスト0           │
│                                                         │
│  これらは意識されずに自動で走る前提                         │
│  思考はこの世界の上で操作を行うこと                         │
└─────────────────────────────────────────────────────────┘
```

思考とは、この脳内世界の上で操作を行うことである。操作には処理コストがかかり、脳の処理容量には上限がある。

### 処理コストの分配原理

**関数化済みの前提**はコストほぼゼロで自動的に走る。意識する必要すらない。

**関数化されていない要素**が脳の処理容量を消費する。

$$\text{思考の処理コスト} \approx \sum \text{関数化されていない要素の構築・保持コスト}$$

脳内世界の前提をそのまま使える概念は、処理コストが低い。前提を変更する必要がある概念ほど、処理コストが高い。

$$\text{シミュレーションコスト} \approx \text{変更すべき前提の数} \times \text{各前提の再構築コスト}$$

### 思考の限界

> **思考の限界とは、関数化されていない要素の総量が脳の処理容量を超える地点である。**

関数化されていない要素が脳のキャパシティを独占する。前提として蓄積されている感覚的関数が多い領域ほど思考コストは激減し、蓄積がない領域ほどコストが爆発する。

### 処理コストによる現象の説明

|現象|説明|
|---|---|
|専門家と素人の差|専門家は大量の前提が関数化済み。思考の本題にキャパシティを全振りできる。素人は前提の構築だけで容量を使い切る|
|「考えると疲れる」|関数化されていない要素を多数同時に保持・操作している時の消耗。得意な領域では疲れにくいのは、前提がほぼ自動で走るから|
|理解の段階性|最初はすべてが未関数化で容量を圧迫。学習が進むと要素が一つずつ関数化され、バックグラウンドに沈む。空いた容量で高次の操作が可能に。Learning文書の「驚きの漸進的減少」の実体|
|概念の「難しさ」|抽象度が高いから難しいのではない。既存の感覚的関数からの差分が大きいから難しい。相対性理論が難しいのは、時空の分離という一度も疑ったことのない前提を書き換える必要があるから|
|教育の本質|差分を最小化する順序設計。各ステップの差分を脳のキャパシティ内に収め、段階的に前提を書き換える。到達不能に見える概念にも到達できる|
|比喩の有用性|既存の関数化済み前提を流用させることで処理コストを下げる装置|

## 第八章：論理学と数学

- **論理学**：すべての関係構造（包含、排除、含意、矛盾、等価など）の接続規則を扱う体系
- **数学**：「数」「量」「構造」の領域における関係構造の精密な操作体系

両者は感覚語なしに関係構造だけで操作を回すことができる（＝計算）。しかし、その操作を「理解している」と言えるのは、四経路のいずれかを通じて感覚化できる場合のみ。

## 第九章：循環構造

経路4（論理的生成）の存在により、体系は一方向ではなく循環する。

```
  感覚
   │
   ▼ 圧縮
  感覚語（統合的近似値。自立的）
   │
   ▼ 反復パターン抽出
  関係構造（抽象的鋳型。非自立的・感覚語依存）
   │
   ├─ 計算（感覚語なしの操作。理解ではない）
   │
   ├─ 理解（四経路で感覚化）
   │    │
   │    └─ 経路4：論理的生成
   │             │
   │             ▼
   │        脳内シミュレーション（処理コスト発生）
   │             │
   │             │ コスト ≈ 既存関数からの差分
   │             │ 差分小 → 低コスト → 容易
   │             │ 差分大 → 高コスト → 困難 or 不可能
   │             │
   │             ▼
   │        感覚として定着
   │             │
   └─────────────┘
          新たな感覚語の素材になる
               │
               ▼
          さらに高次の関係構造の抽出 → …
```

この再帰が、思考の抽象度が際限なく上がっていける理由であり、Learning文書のLevel 5（関数の合成）の基盤である。ただし各サイクルには処理コストがかかり、脳のキャパシティが上限を規定する。
