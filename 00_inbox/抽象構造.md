
## 知識の4つの相（Phase）

知識は「分野」ではなく「相」で分かれる。 同じ対象（心臓でも、プログラムでも、国家でも）に対して、4つの相が存在する。

### 1. 記述の相 — What is it?

- 対象を識別し、名前をつけ、分類する
- 「これは何か」「どこにあるか」「何と何に分かれるか」
- 解剖学、分類学、地理、データ構造の定義、品詞の分類
- この相だけでは理解にならない。カタログに過ぎない

### 2. 機構の相 — How does it work?

- 対象がどう動くか、何が何を引き起こすか
- 因果の連鎖、メカニズム、プロセス
- 生理学、物理法則、アルゴリズム、経済メカニズム
- 「一段下」の理解はここで起きる

### 3. 判断の相 — What should we do?

- 対象に対してどう行動すべきか
- 価値、倫理、意思決定、トレードオフ
- 臨床判断、設計思想、政策決定、倫理学
- 機構の相なしにここへ来ると、根拠のない意見になる

### 4. 表現の相 — How do we communicate it?

- 理解したことをどう他者に伝えるか
- 言語、数式、図、音楽、コード、物語
- 論文執筆、プレゼン、教育、芸術、プログラミング
- AIとの対話もここに属する

## 知識の3つの軸（Axis）

4つの相が「縦」だとすると、知識には「横」に3つの軸がある。

### スケール軸 — どの大きさで見ているか

```
素粒子 → 原子 → 分子 → 細胞 → 組織 → 個体 → 集団 → 社会 → 文明 → 生態系
```

- 同じ「相」でもスケールが変わると法則が変わる
- 分子の記述（化学式）と社会の記述（統計）は同じ「記述の相」だが言語が違う
- スケールの境界で「創発」が起きる：分子に意識はないが、脳には意識がある

### 時間軸 — どの時間幅で見ているか

```
ナノ秒（化学反応） → 秒（神経信号） → 分〜時間（生理） → 日〜年（個人の変化） → 世代（文化） → 世紀（文明） → 地質時代
```

- 同じ対象でも時間幅を変えると見えるものが変わる
- 心臓：ミリ秒単位ではイオンチャネル、分単位では心拍リズム、年単位ではリモデリング
- 短い時間の現象は長い時間の現象の「素材」になる

### 確実性の軸 — どれだけ確かか

```
論理的必然（数学） → 再現可能な法則（物理） → 統計的傾向（医学・社会科学） → 解釈（人文学） → 直感・暗黙知（実践知）
```

- 左に行くほど「誰がやっても同じ結果」
- 右に行くほど「経験と文脈に依存する」
- AIが最も得意なのは左側、人間が最も必要とされるのは右側
- 「正しい」の意味自体がこの軸上で変わる

## 知識の接続パターン

分野を超えて知識が繋がるとき、そのパターンは限られている。

### 類推（Analogy）

- 異なるスケール・対象で同じ構造が現れる
- 所有権（Rust） ≈ 酵素の基質特異性（生化学）
- フィードバックループ（制御工学） ≈ ホメオスタシス（生理学）
- 類推は理解を加速するが、破綻点を常に確認する必要がある

### 階層（Hierarchy）

- 下の層が上の層の部品になる
- 原子 → 分子 → 細胞 → …
- 関数 → モジュール → クレート → …
- 上の層は下の層の「振る舞いの要約」

### 対立（Tension）

- 最適化しようとすると別の何かが犠牲になる
- 安全性 vs 自由（法律）
- 感度 vs 特異度（診断）
- 速度 vs メモリ（計算機科学）
- 対立の存在を知っていることが判断の質を決める

### 変換（Translation）

- 同じ現象を別の言語で記述する
- 心房細動：臨床では「irregularly irregular」、生理学ではリエントリー、数学ではODE系、Rustではstruct AF
- 変換できる言語が多いほど、AIに聞ける角度が増える

## この地図の使い方

1. 何かを学ぶとき、今自分が4つの相のどこにいるかを意識する
    - 記述で止まっていないか？ 機構まで降りているか？
2. 何かを理解できないとき、3つの軸のどこで見ているかを変えてみる
    - スケールを一つ上げる/下げる
    - 時間幅を広げる/狭める
    - 確実性の位置を確認する（数学的に解けるのか、統計的にしか言えないのか）
3. AIに聞くとき、4つの接続パターンのどれを使っているかを明示する
    - 「これはXとの類推で理解できる？」
    - 「この階層の一段下は何？」
    - 「ここのトレードオフは何？」
    - 「これを別の言語（数式/コード/臨床用語）で言うとどうなる？」

## 未踏領域の認識

この地図に載っていないもの：

- 自分がまだ「相」の存在すら知らない領域
- 接続パターンがまだ発見されていない分野間の関係
- 確実性の軸の右端にある、言語化できない実践知
- 地図そのものを描き直す必要が出てくる、パラダイムシフト

地図は完成しない。重要なのは「地図の外がある」と知っていること。
