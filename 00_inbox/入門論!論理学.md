
### 論理とは？
- 言葉と言葉の関係の一種
論理は非常識か？
	論理的可能性は非常識な可能性をも許容する

### 論理的な推論
```
- 論理的な推論は、その一つ一つのステップを取り出してみるとアホらしいほど当たり前。
- そのステップが積み重なることによって最初は思っても見なかった結論に到達することがある。
- 一つ一つのステップが当たり前だからこそ、それを辿ることによって誰もがその結論を受け入れることになる。
```
*論理学ではひとつひとつのステップを構成している代表的な推論を見ていく。ミクロに見るとそれは当たりのものに見えるはずだ、しかしそれを組み合わせることにより複雑な推論を理解し、作り上げることが可能になる。*

- 論証 : ある前提からなんらかの結論を導くその全体
- 導出 : 前提から結論を導くその過程
	- 演繹(推論) : 前提を認めたら必ずその結論も認めなければならない導出
	- 推測 : 常識や経験からおそらく言えるだろうという結論の導出

#### *推論は言葉と言葉の関係を扱います。まさに、前提と結論の関係を、その関係だけを、論理は扱うのです。*


### 論理学で重要な言葉たち
*全ての言葉が論理学では使用可能だが、その中でも汎用性の高さが重要度を決める。*


- 否定語 : ではない
- 接続後 : そして、または、ならば...etc
プラス
- 全て
- 存在する

この言葉たちを巡って一つの完結したまとまり（命題理論）を作り上げる。

### 否定
*主張Aの打ち消し*
- この世界はあるという概念で構成されている。
- Aがある（肯定）はその存在を描写してるのに対し、否定は肯定の否定でしかない。
- ない状態を描写することはできない。
#### 積極的な内容を示唆する否定

ex.対概念がある時の否定。
	*対概念とは好きに対する嫌いや、美味しいに対する不味いなど。
	このような状況下での日常的な否定は対概念に否定の意味が引っ張られる。*

*『A』という主張の否定は、『A』と主張すると間違いになる全ての場合を含む。*

### 肯定するか否定するかのどっちかしかない？
- 論理法則
	論理的に言って必ず成り立つ命題。
- 排中律（はいちゅうりつ）
	論理法則の一種。
	『A』または『Aじゃない』かのどちらか、その中間を排する。

排中律とは
```
『A』または『Aではない』
```
である。

*排中律を認める標準的な論理体系『神の論理学』*
- 曖昧な概念を扱わない
- 神の視点で語る
*排中律を認めない非標準的な論理体系『人間の論理学』*
- 曖昧な概念を扱う
- 証拠を必要とする

### 二重否定則
『A』が正しいのなら、『A』の二重否定も正しい。
```
二重否定入れ
A → (Aではない)ではない

二重否定取り
(Aではない)ではない → A
```
if 非中律を認める
	両方成り立つ
else 非中律を認めない
	二重否定取りが成り立たない

### 矛盾の形
*矛盾は世界の側にあるのではなく、世界を捉える人間の側に生まれる（主張の両立不可能性）。*
- 『A』かつ『A』ではない
この形が含まれる主張を矛盾と呼ぶ。

#### 矛盾律
```
(『A』かつ(『A』ではない)) ということはない。
```
-　矛盾の否定。
-　矛盾律は上の主張が必ず正しいとするもの。

### 背理法
(今までのものが直接論証だったのに対しこれは間接論証である。)
- 『Aではない』と言えるのは『A』と主張すると間違いになる時だ。　
つまり
```
『A』を仮定して矛盾が導かれる時『Aではない』と結論して良い。
```
