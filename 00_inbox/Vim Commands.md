# Vim — Command Reference

Vimはモード切り替え式のテキストエディタ。マウスを使わず、すべてをキーボードで操作する。慣れると他のどのエディタよりも速い。

---

## Modes — モード

Vimの最大の特徴。4つのモードを切り替えて操作する。

|Mode|役割|入り方|
|---|---|---|
|Normal|移動・削除・コピーなどの操作|`Esc`|
|Insert|テキストを入力する|`i`, `a`, `o` など|
|Visual|テキストを選択する|`v`, `V`, `Ctrl+v`|
|Command|コマンドを実行する（保存・終了など）|`:`|

起動時はNormalモード。まずこれを理解しないと何も打てなくて混乱する。テキストを打ちたい時だけInsertに入り、終わったら`Esc`でNormalに戻る。

---

## Normal Mode — ノーマルモード

ほとんどの時間をここで過ごす。移動・編集・検索のコマンドはすべてここ。

### Movement — 移動

|Key|動作|
|---|---|
|`h`|左|
|`j`|下|
|`k`|上|
|`l`|右|
|`w`|次の単語の先頭へ|
|`b`|前の単語の先頭へ|
|`e`|現在の単語の末尾へ|
|`0`|行頭へ|
|`$`|行末へ|
|`^`|行の最初の文字へ（空白を飛ばす）|
|`gg`|ファイルの先頭へ|
|`G`|ファイルの末尾へ|
|`{number}G`|指定した行へ（例：`42G`で42行目）|
|`Ctrl+d`|半ページ下にスクロール|
|`Ctrl+u`|半ページ上にスクロール|
|`%`|対応する括弧へジャンプ|
|`f{char}`|現在行で次の{char}へジャンプ（例：`fa`で次のaへ）|
|`F{char}`|現在行で前の{char}へジャンプ|

### Editing — 編集

|Key|動作|
|---|---|
|`x`|カーソル位置の1文字を削除|
|`dd`|行を削除（カット）|
|`dw`|カーソルから単語末まで削除|
|`d$` or `D`|カーソルから行末まで削除|
|`d0`|カーソルから行頭まで削除|
|`cc`|行を削除してInsertモードに入る|
|`cw`|単語を削除してInsertモードに入る|
|`c$` or `C`|カーソルから行末まで削除してInsertに入る|
|`r{char}`|カーソル位置の文字を{char}に置換|
|`~`|大文字/小文字を切り替え|
|`yy`|行をコピー（ヤンク）|
|`yw`|単語をコピー|
|`p`|カーソルの後にペースト|
|`P`|カーソルの前にペースト|
|`u`|undo（元に戻す）|
|`Ctrl+r`|redo（やり直す）|
|`.`|直前の操作を繰り返す|
|`J`|現在行と次の行を結合|

### The Grammar of Vim — Vimの文法

Vimのコマンドは**動詞 + 数 + 名詞**の構造を持つ。これが関数的。

```
d    = delete（削除）     ← 動詞
2    = 2回               ← 数（省略可能）
w    = word（単語）       ← 名詞（動作対象）

d2w  = 2単語を削除
```

|動詞|意味|
|---|---|
|`d`|delete（削除）|
|`c`|change（削除してInsertに入る）|
|`y`|yank（コピー）|
|`v`|visual select（選択）|

|名詞|意味|
|---|---|
|`w`|word（単語）|
|`$`|end of line（行末まで）|
|`0`|beginning of line（行頭まで）|
|`gg`|beginning of file（ファイル先頭まで）|
|`G`|end of file（ファイル末尾まで）|
|`i(`|inside parentheses（括弧の中身）|
|`i"`|inside quotes（引用符の中身）|
|`i{`|inside braces（中括弧の中身）|
|`a(`|around parentheses（括弧ごと）|

組み合わせ例：

|Command|意味|
|---|---|
|`d2w`|2単語削除|
|`ci"`|引用符の中身を削除してInsert|
|`di(`|括弧の中身を削除|
|`ya{`|中括弧ごとコピー|
|`dG`|カーソルからファイル末尾まで削除|
|`c$`|カーソルから行末まで削除してInsert|
|`3dd`|3行削除|
|`5j`|5行下に移動|

この文法を覚えれば、個別のコマンドを暗記する必要がほぼなくなる。

## Insert Mode — インサートモード

テキストを入力するモード。Normalモードから入る方法が複数ある。

|Key|動作|
|---|---|
|`i`|カーソルの前から入力開始|
|`a`|カーソルの後から入力開始|
|`I`|行頭から入力開始|
|`A`|行末から入力開始|
|`o`|下に新しい行を作って入力開始|
|`O`|上に新しい行を作って入力開始|
|`Esc`|Normalモードに戻る|

Insertモードでは普通のテキストエディタと同じように打てる。

---

## Visual Mode — ビジュアルモード

テキストを選択するモード。選択した後にコマンドを適用できる。

|Key|動作|
|---|---|
|`v`|文字単位で選択開始|
|`V`|行単位で選択開始|
|`Ctrl+v`|矩形（ブロック）選択|

選択した後：

|Key|動作|
|---|---|
|`d`|選択範囲を削除|
|`y`|選択範囲をコピー|
|`c`|選択範囲を削除してInsertに入る|
|`>`|選択範囲をインデント|
|`<`|選択範囲のインデントを減らす|
|`~`|大文字/小文字を切り替え|
|`Esc`|選択を解除してNormalに戻る|

---

## Command Mode — コマンドモード

Normalモードで`:`を押すと入る。ファイル操作やシステムコマンドを実行。

### File Operations — ファイル操作

|Command|動作|
|---|---|
|`:w`|保存|
|`:q`|終了|
|`:wq`|保存して終了|
|`:q!`|保存せず強制終了|
|`:w filename`|別名で保存|
|`:e filename`|別のファイルを開く|

### Search and Replace — 検索と置換

|Command|動作|
|---|---|
|`/pattern`|前方検索（`n`で次、`N`で前）|
|`?pattern`|後方検索|
|`*`|カーソル位置の単語を前方検索|
|`#`|カーソル位置の単語を後方検索|
|`:%s/old/new/g`|ファイル全体でoldをnewに置換|
|`:%s/old/new/gc`|確認しながら置換|
|`:s/old/new/g`|現在行だけ置換|

### Other Useful Commands — その他

|Command|動作|
|---|---|
|`:set number`|行番号を表示|
|`:set nonumber`|行番号を非表示|
|`:set relativenumber`|相対行番号を表示|
|`:{number}`|指定行にジャンプ|
|`:!{command}`|ターミナルコマンドを実行（例：`:!cargo run`）|
|`:split`|画面を水平分割|
|`:vsplit`|画面を垂直分割|

---

## Window Navigation — ウィンドウ操作

画面分割した時の移動。

|Key|動作|
|---|---|
|`Ctrl+w h`|左のウィンドウへ|
|`Ctrl+w j`|下のウィンドウへ|
|`Ctrl+w k`|上のウィンドウへ|
|`Ctrl+w l`|右のウィンドウへ|
|`Ctrl+w =`|ウィンドウサイズを均等に|
|`Ctrl+w q`|現在のウィンドウを閉じる|

---

## Marks and Jumps — マークとジャンプ

特定の位置に名前をつけて、後からジャンプする。

|Key|動作|
|---|---|
|`m{a-z}`|現在位置にマークを設定（例：`ma`）|
|`'{a-z}`|マークの行にジャンプ（例：`'a`）|
|`` `{a-z} ``|マークの正確な位置にジャンプ|
|`Ctrl+o`|前のジャンプ位置に戻る|
|`Ctrl+i`|次のジャンプ位置に進む|

---

## Macros — マクロ

操作を録画して繰り返し実行する。繰り返し作業の自動化。

|Key|動作|
|---|---|
|`q{a-z}`|マクロの録画開始（例：`qa`でレジスタaに録画）|
|`q`|録画停止|
|`@{a-z}`|マクロを実行（例：`@a`）|
|`@@`|直前のマクロを再実行|
|`10@a`|マクロaを10回実行|

---

## Essential Combos — よく使う組み合わせ

|Combo|動作|
|---|---|
|`ciw`|単語を丸ごと書き換え|
|`ci"`|引用符の中を書き換え|
|`di(`|括弧の中を削除|
|`da{`|中括弧ごと削除|
|`yiw`|単語をコピー|
|`vip`|段落を選択|
|`ggVG`|ファイル全体を選択|
|`gg=G`|ファイル全体をインデント修正|
|`xp`|2文字を入れ替え|
|`ddp`|2行を入れ替え|

## Learning Path — 学習の順序

一度に全部覚えようとしない。この順で少しずつ：

1. **最初:** `i`, `Esc`, `:wq`, `:q!` — 入力と保存と終了だけ
2. **次に:** `h`,`j`,`k`,`l`, `w`,`b` — マウスなしで移動
3. **その次:** `dd`, `yy`, `p`, `u` — 基本編集
4. **慣れたら:** 動詞+名詞の文法（`d2w`, `ci"`, `da{`）
5. **さらに:** `/`検索、`:%s`置換、Visual mode
6. **上級:** マクロ、マーク、ウィンドウ分割
