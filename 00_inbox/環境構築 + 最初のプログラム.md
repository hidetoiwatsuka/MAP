
```c
#include <stdio.h>

int main (void){

	printf("hello world");
	return 0;

}
```

| 要素              | 略・由来                                  | 意味                                    |
| --------------- | ------------------------------------- | ------------------------------------- |
| `#`             | preprocessor directive                | コンパイル前にプリプロセッサが処理する命令の印               |
| `include`       | include（含める）                          | 指定ファイルの中身をここに挿入せよ                     |
| `<` `>`         | angle brackets                        | 標準ライブラリのパスから探す指定（`""` だとカレントディレクトリ優先） |
| `stdio`         | **st**an**d**ard **i**nput/**o**utput | 標準入出力                                 |
| `.h`            | **h**eader                            | ヘッダファイル（関数の宣言が書いてあるファイル）              |
| `int`           | **int**eger                           | 整数型                                   |
| `main`          | main（主要な）                             | プログラムの開始地点となる関数名。OSがここを呼ぶ             |
| `(` `)`         | parentheses                           | 関数の引数リストを囲む                           |
| `void`          | void（空）                               | 「何もない」＝引数なし                           |
| `{` `}`         | braces / curly brackets               | ブロック（コードのまとまり）の開始と終了                  |
| `printf`        | **print** **f**ormatted               | 書式付きで出力する関数                           |
| `"hello world"` | string literal                        | 文字列リテラル（ダブルクォートで囲んだ文字列データ）            |
| `;`             | semicolon                             | 文（statement）の終端を示す                    |
| `return`        | return（返す）                            | 呼び出し元に値を返す                            |
| `0`             | exit code                             | 正常終了を意味する終了コード                        |
ただ `int` が出てくる場面は2つあって：

|場面|例|意味|
|---|---|---|
|変数宣言|`int x = 10;`|メモリ確保 + 型指定|
|関数の戻り値型|`int main(void)`|この関数が返す値の型を宣言（メモリ確保とはちょっと違う）|

さっきの `int main(void)` の `int` は「main関数は整数を返しますよ」という宣言であって、変数を作ってるわけではない。

---

**行ごとのまとめ**

`#include <stdio.h>` — 「標準入出力ヘッダファイルの中身をここに貼り付けろ」というプリプロセッサへの命令。これがないと `printf` が未宣言になる。

`int main(void) {` — 「引数なし・整数を返す `main` 関数をここから始める」。OSはプログラム起動時にこの `main` を呼び出す。

`printf("hello world");` — 「`hello world` という文字列を標準出力（ターミナル）に表示せよ」。

`return 0;` — 「呼び出し元（OS）に 0（正常終了）を返して関数を終了する」。

`}` — `main` 関数ブロックの終わり。

```c
#include <stdio.h>

int main (void){
	printf("%d",100);
	return 0;
}
```
`%d` はフォーマット指定子（format specifier）。`printf` に「この位置にこの型の値を埋め込め」と指示するもの。

`printf("テンプレート文字列", 埋め込む値)` という構造で、`%d` の部分が `100` に置き換わって出力される。

**主要なフォーマット指定子：**

|指定子|略・由来|表示する型|
|---|---|---|
|`%d`|**d**ecimal|整数（10進数）|
|`%f`|**f**loat|浮動小数点数|
|`%c`|**c**har|文字1つ|
|`%s`|**s**tring|文字列|
|`%x`|he**x**|整数（16進数）|
|`%o`|**o**ctal|整数（8進数）|
|`%%`|—|`%` 自体を表示|

例えば `printf("Score: %d, Rate: %f", 95, 3.14)` なら `Score: 95, Rate: 3.140000` と出る。複数の `%` に対して、カンマ区切りで順番に値を渡す仕組み。

```c
#include <stdio.h>

int main (void){

	printf("%d*%d=%d\n",100,3,300);
	printf("total is %d",300);
	return 0;

}
```

```c
#include <stdio.h>

int main (void){

	printf("%f\n" ,3.14*3);
	printf("%d" ,12+3-8);
	return 0;

}
```
