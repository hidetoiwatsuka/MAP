## Core Thesis — 中核命題

Learning is the process of building functions inside the brain through repeated input-output cycles.

At birth, the brain contains almost no functional models. It has no understanding of physics, no language, no motor coordination, no concept of cause and effect. What it does have is **drive** — raw, undirected need-states. Hunger. Discomfort. Craving for warmth. Aversion to pain. In Buddhist terms: 煩悩 (bonno) — fundamental desires with no means of fulfillment.

These drives are the **only initial inputs**. The brain starts with wants but no methods. It knows _that_ it needs, but not _how_ to get what it needs.

Learning is the process of acquiring the _how_.

（生まれた時、脳には有用な関数がほぼ存在しない。物理法則のモデルも、言語も、運動制御も、因果関係の理解もない。あるのは煩悩 — 充足の手段を持たない根源的な欲求のみ。学習とは「how」を獲得する過程。）

---

## The Starting State — 初期状態

$$\text{drive (raw need)} \xrightarrow{f = \text{???}} \text{satisfaction}$$

The newborn brain is a function with **defined input** (drives), a **desired output** (satisfaction), and an **empty process**. The function exists in skeleton form — input and output are given by biology, but the transformation rules are missing.

The entire project of learning is filling in that process box.

（新生児の脳は、入力（欲求）と望ましい出力（満足）が定義されているが、処理が空の関数。学習の全プロジェクトは、その処理の箱を埋めること。）

---

## The Mechanism — メカニズム

### Trial, error, and function formation

The brain builds functions through a cycle:

1. **Input** — a stimulus arrives (sensation, situation, problem, need)
2. **Process** — the brain applies whatever internal model it currently has (initially almost nothing)
3. **Output** — an action, response, or prediction is produced
4. **Feedback** — reality responds. The output either works or doesn't.
5. **Update** — the brain adjusts the internal model based on the mismatch between expected and actual outcome

$$\text{input} \xrightarrow{f_{\text{current}}} \text{output} \xrightarrow{\text{compare with reality}} \text{error signal} \xrightarrow{\text{update}} f_{\text{improved}}$$

Each cycle refines the internal function. Over thousands of repetitions, the function moves from random guessing toward reliable transformation. This is what "learning" feels like from the inside — the gradual reduction of surprise.

（各サイクルが内部関数を精錬する。数千回の繰り返しを経て、関数はランダムな推測から信頼性のある変換へと移行する。これが「学習」の内的体験 — 驚きの漸進的減少。）

### Prediction error as the learning signal

Neurologically, this is the dopaminergic prediction error system. When an outcome is **better than expected**, dopamine fires — reinforcing the function that produced the action. When an outcome is **worse than expected**, dopamine dips — weakening that function. When the outcome **matches expectation exactly**, nothing fires — the function is stable, learning is complete for that pattern.

（神経学的には、ドーパミン予測誤差システム。予想より良い結果→ドーパミン発火→関数を強化。予想より悪い→ドーパミン低下→関数を弱化。予想通り→発火なし→その関数は安定、学習完了。）

## What Gets Learned — 何が学習されるか

Every domain of human competence is a function built through this process. The content differs, but the mechanism is identical.

### Perception — 知覚

The brain learns to map raw sensory data to meaningful categories.

$$\text{photons hitting retina} \xrightarrow{f} \text{"that is a face"}$$

$$\text{pressure waves in air} \xrightarrow{f} \text{"that is my mother's voice"}$$

A newborn sees only undifferentiated light and shadow. Through millions of input-output-feedback cycles, the visual cortex builds functions that extract edges, shapes, objects, faces, expressions. The infant doesn't know it's "learning to see" — it is constructing visual functions through exposure.

（新生児は未分化の光と影しか見えない。数百万のサイクルを経て、視覚野がエッジ・形状・物体・顔・表情を抽出する関数を構築する。）

### Language — 言語

The brain learns to map sounds to meanings, and meanings to sounds.

$$\text{sound pattern "water"} \xrightarrow{f} \text{concept of water}$$

$$\text{thirst + concept of water} \xrightarrow{f} \text{producing the sound "water"}$$

This is a bidirectional function, built through thousands of pairings between sensory input (hearing "water" while seeing/touching water) and feedback (saying "water" and receiving water). The linking of perception to symbol is function construction.

（知覚と記号の結びつけは関数の構築。「水」という音と水の感覚を繰り返し対にすることで、双方向の関数が形成される。）

### Motor control — 運動制御

$$\text{intention to grasp} \xrightarrow{f} \text{coordinated muscle activation}$$

An infant reaches for objects and misses. Each attempt generates an error signal — the hand didn't go where the brain predicted. Over hundreds of attempts, the motor cortex and cerebellum build a function that accurately maps intention to movement. Walking, writing, playing guitar — every motor skill is a refined function.

（乳児は物に手を伸ばして外す。毎回の試行がエラー信号を生成。数百回の試行を経て、意図を運動に正確にマッピングする関数が構築される。）

### Physics — 物理法則の理解

$$\text{observation of falling object} \xrightarrow{f} \text{prediction: "it will hit the ground"}$$

No one teaches a toddler gravity. The child drops things, throws things, watches things fall — and the brain builds an internal physics engine. By age 2, a child can predict trajectories, understand that unsupported objects fall, and anticipate collisions. This intuitive physics is a set of functions built entirely from observation and feedback.

（誰も幼児に重力を教えない。物を落とし、投げ、落ちるのを見ることで、脳が内部物理エンジンを構築する。直感的物理学は、観察とフィードバックのみから構築された関数の集合。）

### Social understanding — 社会的理解

$$\text{other person's behavior} \xrightarrow{f} \text{prediction of their intention}$$

Theory of mind — the ability to infer what others are thinking — is a function built through social interaction. Children learn that certain facial expressions predict certain behaviors, that tone of voice signals emotional state, that actions have social consequences. Each social interaction is an input-output cycle that refines the social prediction function.

（心の理論 — 他者の思考を推測する能力 — は、社会的相互作用を通じて構築された関数。）

## Drives as the Bootstrap — 煩悩がブートストラップ

The drives (煩悩) are not obstacles to learning — they are the **engine** of learning. Without desire, there is no motivation to process inputs. Without discomfort, there is no error signal. The system needs a "should be" to compare against "what is."

$$\text{error} = \text{what I want (drive)} - \text{what I have (current state)}$$

This error is what powers every learning cycle. A baby doesn't learn to reach because reaching is intellectually interesting. It learns to reach because it **wants the object** and the failure to grasp it generates a prediction error that updates the motor function.

Drives determine **what** gets learned by directing attention and assigning value. The brain doesn't build functions for everything it encounters — it prioritizes building functions for things that are relevant to its drives. This is why emotionally significant experiences are learned faster and retained longer.

（煩悩は学習の障害ではなく、学習のエンジン。欲求なしには入力を処理する動機がない。不快なしにはエラー信号がない。煩悩が「何を」学ぶかを決定する — 脳は欲求に関連するものを優先的に学習する。）

## External Functions vs. Internal Functions — 外的関数と内的関数

A critical distinction:

- **External functions（外的関数）** — the actual rules governing reality. Gravity, thermodynamics, social dynamics, language structure. These exist independent of the observer.
- **Internal functions（内的関数）** — the brain's approximation of those external functions. Always incomplete, sometimes wrong, continuously refined.

Learning is the progressive alignment of internal functions with external functions. The internal model never perfectly matches reality — but it gets close enough to be useful. A physicist's internal model of gravity is closer to the external function than a toddler's, but both are approximations.

（学習とは、内的関数を外的関数に漸進的に整合させていくこと。内的モデルは現実と完全には一致しない — しかし実用に足るほど近づく。）

$$f_{\text{internal}} \xrightarrow{\text{learning}} f_{\text{internal}} \approx f_{\text{external}}$$

### Misalignment is the source of error — and of discovery

When the internal function produces a prediction that doesn't match reality, two things can happen:

1. **The internal function is wrong** → update it (normal learning)
2. **The internal function reveals something unexpected about the external function** → discovery, insight, paradigm shift

Science is the systematic process of testing internal functions against external reality and updating them. Education is the transfer of refined internal functions from one brain to another, saving the recipient from having to build them from scratch.

（内的関数が現実と一致しない時、2つのことが起こりうる：内的関数の更新（通常の学習）、または外的関数についての予想外の発見。科学は内的関数を外的現実に対して体系的に検証し更新する過程。教育は精錬された内的関数をある脳から別の脳に転送すること。）

## Levels of Function Acquisition — 関数獲得の段階

Learning does not stop at acquiring individual functions. It progresses through levels of abstraction:

### Level 1: Stimulus-response（刺激-反応）

Direct mapping. Hot stove → pull hand away. No intermediate reasoning.

### Level 2: Pattern recognition（パターン認識）

Recognizing regularities across multiple inputs. "Every time I drop something, it falls down." The brain extracts a general function from repeated instances.

### Level 3: Model building（モデル構築）

Constructing internal models that can predict novel situations. "If I throw this ball at that angle, it will land approximately there." The function generalizes beyond direct experience.

### Level 4: Abstraction（抽象化）

Recognizing that the same function structure appears across different domains. "Exponential growth applies to bacteria, compound interest, and viral spread — the underlying function is the same." This is the level where the concept of "function" itself is understood.

### Level 5: Function composition（関数の合成）

Combining learned functions to create new ones that were never directly taught. This is creativity, problem-solving, and theoretical thinking — assembling existing internal functions into novel configurations.

（学習は個別の関数の獲得で止まらない。刺激-反応→パターン認識→モデル構築→抽象化→関数の合成へと抽象度を上げていく。レベル5が創造性と理論的思考 — 既存の内的関数を新しい構成に組み立てること。）

## Implications — 示唆

### Why repetition works（反復が機能する理由）

Repetition is not mindless copying. Each repetition is an input-output-feedback cycle that incrementally refines the internal function. The function becomes faster, more accurate, more automatic. What starts as conscious, effortful processing becomes unconscious, effortless execution — the function has been compiled.

### Why understanding beats memorization（理解が暗記に勝る理由）

Memorization stores individual input-output pairs. Understanding builds the function itself. With the function, you can handle inputs you've never seen before. With memorized pairs, you can only handle what you've already encountered.

$$\text{Memorization: } {x_1 \to y_1,\ x_2 \to y_2,\ \ldots}$$ $$\text{Understanding: } f(x) \to y \quad \text{for any } x$$

### Why teaching deepens learning（教えることが学びを深める理由）

Teaching forces you to externalize your internal function — to make the implicit process explicit. This reveals gaps and inconsistencies in your own model that passive learning never exposes.

### Why sleep matters（睡眠が重要な理由）

During sleep, the brain consolidates functions — pruning weak connections and strengthening useful ones. It runs the functions offline, testing and optimizing them without real-world consequences. Sleep is function maintenance.

## The Model as a Function — このモデル自体が関数

This concept — "learning is function acquisition" — is itself a function you just acquired.

$$\text{reading this document (input)} \xrightarrow{f_{\text{your brain}}} \text{new internal model of learning (output)}$$

If this model is useful — if it helps you predict, explain, or navigate learning more effectively — then your internal function has been updated. If it doesn't match your experience, the prediction error is your signal to refine it further.

（このconceptを読むこと自体が、学習に関する新しい内的関数の獲得。このモデルが有用なら内的関数が更新された。経験と合わなければ、予測誤差がさらなる精錬のシグナル。）
