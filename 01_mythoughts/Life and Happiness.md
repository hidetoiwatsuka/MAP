## Core Thesis — 中核命題

Humans cannot perceive value in absolute terms. Good and bad, pleasure and pain, happiness and misery — all are experienced only through **comparison**. There is no internal sensor that reads "happiness level: 73%." There is only "better than before," "worse than expected," "more than them," "less than I had."

Life is a continuous loop of relative evaluation, response, and function acquisition. Happiness is not a destination within this loop — it is the state where the loop is running well.

（人間は価値を絶対的に知覚できない。良し悪し、快不快、幸不幸 — すべて比較を通じてのみ体験される。人生は相対評価・反応・関数獲得の連続ループ。幸福はこのループ内の目的地ではなく、ループがうまく回っている状態。）

## The Evaluation Is Always Relative — 評価は常に相対的

Every judgment the brain makes is a comparison between a current state and a reference point. The reference point shifts constantly, which is why the same objective condition can feel like heaven or hell depending on context.

（脳が下すあらゆる判断は、現在の状態と基準点の比較。基準点は常に移動する。だから同じ客観的状況が、文脈次第で天国にも地獄にもなる。）

### Two axes of comparison — 比較の2軸

**Temporal（時間的）:** Current self vs. past self.

$$\text{evaluation} = \text{current state} - \text{remembered state}$$

"Am I better off than I was?" If yes → positive signal. If no → negative signal. This is why improvement feels good even from a low baseline, and why stagnation at a high level feels empty.

（「以前の自分より良くなっているか？」向上は低い水準からでも心地よく、高い水準での停滞は空虚に感じる。）

**Social（社会的）:** Self vs. others in the group.

$$\text{evaluation} = \text{my position} - \text{perceived position of others}$$

"Where do I stand relative to those around me?" This is not vanity — it is an evolved survival mechanism. Accurate assessment of one's position within a group was critical for resource access, mate selection, and coalition formation. Those who misjudged their standing either overreached (and were punished) or underreached (and missed opportunities).

（集団内での自分の立ち位置を正確に把握することは、資源へのアクセス、配偶者選択、連合形成に不可欠だった。これは虚栄ではなく生存メカニズム。）

### Why relative evaluation is fundamental — なぜ相対評価が根本的か

Humans are group-living animals. Survival and reproduction were never determined by absolute resource levels — they were determined by **relative position** within the social hierarchy. Having enough food meant nothing if others had more and could leverage that advantage. Having skills meant nothing if others had better skills and were chosen over you.

Natural selection did not build brains that evaluate "how much do I have." It built brains that evaluate "how much do I have **compared to what I could have, what I had, and what others have**."

（自然選択は「どれだけ持っているか」を評価する脳を作らなかった。「持ちうるもの・持っていたもの・他者が持っているものと比べてどれだけか」を評価する脳を作った。）

## The Loop — ループ構造

Life operates as a recurring cycle:

```
     ┌─────────────────────────────────────────────┐
     │                                               │
     ▼                                               │
 RELATIVE EVALUATION                                 │
 (current vs. past self / others / expectations)     │
     │                                               │
     ├──→ Positive signal (+)                        │
     │    state ≥ reference                          │
     │    ├─ dopaminergic response          　　　　　 │
     │    │  (pursue more, chase next high)          │
     │    └─ serotonergic response                   │
     │       (maintain, appreciate, sustain)         │
     │       │                                       │
     │       └──→ FUNCTION ACQUIRED ────────────────►│
     │            (what works, what satisfies)       │
     │                                               │
     └──→ Negative signal (−)                        │
          state < reference                          │
          → discomfort, dissatisfaction              │
          │                                          │
          ├─ If discomfort → change behavior         │
          │  (seek new input, try different process) │
          │  │                                       │
          │  └──→ FUNCTION ACQUIRED ────────────────►│
          │       (what to avoid, what to fix)       │
          │                                          │
          └─ If comfort despite negative signal      │
             → stagnation (no function update)       │
             │                                       │
             └──→ loop continues with same functions─┘
```

Each pass through this loop either builds a new function or refines an existing one. Over time, the accumulated functions become your competence, your personality, your wisdom — your life.

（各ループが新しい関数を構築するか、既存の関数を精錬する。時間の経過とともに、蓄積された関数があなたの能力・人格・知恵 — あなたの人生になる。）

## The Two Modes of Positive Response — 正の反応の2つのモード

When evaluation returns a positive signal, the brain's response depends on **maturity of the internal function system** — roughly, how many loops you've completed and how well you've learned from them.

### Dopaminergic mode（ドーパミン的モード）

**Character:** Pursuit. More. Next. Better.

The default response, especially early in life or in unfamiliar domains. A positive signal triggers desire for the next positive signal. Satisfaction is brief — the reference point immediately shifts upward, and the next evaluation requires a higher state to register as positive.

This mode drives exploration, ambition, and growth. It is the engine of function acquisition — without it, there is no motivation to try new inputs and build new functions. But unchecked, it produces the hedonic treadmill: no amount is ever enough because the reference point always moves.

（デフォルトの反応。満足は短く、基準点がすぐ上昇し、次の評価はより高い状態を要求する。探索・野心・成長を駆動するが、歯止めがなければ快楽の踏み車を生む。）

### Serotonergic mode（セロトニン的モード）

**Character:** Stability. Enough. Here.

A more mature response that emerges as internal functions become refined. The brain recognizes that the current state is good — not because it exceeds a reference point, but because the function system is well-calibrated. Satisfaction comes not from exceeding expectations but from the absence of significant mismatch.

This mode sustains contentment, gratitude, and presence. It is associated with stable social bonds, consistent routines, and deep competence in a domain. It does not eliminate desire — it changes the relationship to desire.

（より成熟した反応。現在の状態が良いと認識する — 基準点を超えるからではなく、関数システムが適切に較正されているから。欲求を排除するのではなく、欲求との関係を変える。）

### The shift is not binary — 移行は二項的ではない

Most people oscillate between modes depending on domain. Someone can be serotonergic about their career (stable, content) and dopaminergic about their health (striving, comparing). The modes coexist. Maturation is the gradual expansion of serotonergic capacity without losing dopaminergic drive entirely.

## What Gets Built — 何が構築されるか

Through this loop, specific functions accumulate:

**Self-knowledge functions（自己理解の関数）**

$$\text{emotional state (input)} \xrightarrow{f} \text{understanding of what I actually need (output)}$$

Early in life, this function barely exists. A child feels bad but doesn't know why. Over many loops, the function refines: "I feel this specific discomfort → it means I need this specific thing." Emotional intelligence is the accuracy of this function.

（幼い頃この関数はほぼ存在しない。多くのループを経て精錬される：「この特定の不快感→この特定のものが必要」。感情的知性はこの関数の精度。）

**Strategy functions（戦略の関数）**

$$\text{negative evaluation (input)} \xrightarrow{f} \text{effective response (output)}$$

What to do when things are bad. Fight, flee, adapt, wait, ask for help, change approach. Each negative experience that is processed (not avoided) builds or refines a strategy function.

**Satisfaction functions（満足の関数）**

$$\text{positive evaluation (input)} \xrightarrow{f} \text{sustain or deepen (output)}$$

What to do when things are good. How to maintain a good state without destabilizing it through overreach. How to appreciate without clinging. This function is often underdeveloped because the dopaminergic mode doesn't require it.

**Social calibration functions（社会的較正の関数）**

$$\text{others' behavior + own position (input)} \xrightarrow{f} \text{appropriate response (output)}$$

When to compete, when to cooperate, when to assert, when to yield. Built through social interaction loops. [Sustainable Human Relationships](Sustainable%20Human%20Relationships.md) describes the exchange dynamics that these functions navigate.

## Why Absolute Happiness Cannot Exist — 絶対的幸福が存在し得ない理由

If evaluation is always relative, then happiness is always conditional on the reference point. And the reference point is never fixed:

- **Temporal reference shifts:** Yesterday's achievement becomes today's baseline. The promotion that felt amazing last month is now just normal. This is hedonic adaptation — the reference point chases the current state.
- **Social reference shifts:** Moving to a wealthier neighborhood doesn't make you feel wealthy — it changes your comparison group. The same income that felt abundant among one peer group feels insufficient among another.
- **Internal reference shifts:** As internal functions mature, what once satisfied no longer does. Growth changes what "enough" means.

Therefore: **there is no state that will permanently register as positive**, because any state, once stabilized, becomes the new reference point — and the next evaluation starts from there.

（評価が常に相対的である以上、幸福は常に基準点に条件づけられる。そして基準点は固定されない。昨日の達成は今日の基準線になる。いかなる状態も、安定すれば新しい基準点になり、次の評価はそこから始まる。したがって、永続的に正として登録される状態は存在しない。）

This is not pessimism. It is mechanism.

## What Happiness Actually Is — 幸福の実態

Given that absolute happiness is structurally impossible, what is happiness?

**Happiness is the compound effect of running the evaluation loop well over time.**

Specifically:

1. **Accurate self-knowledge** — the function that maps internal states to actual needs is well-calibrated. You know what you want and why.
2. **Effective response to negative signals** — when evaluation returns negative, you have functional strategies that move you toward improvement rather than stagnation or destructive coping.
3. **Capacity for serotonergic satisfaction** — the ability to register positive states as genuinely good without immediately shifting the reference point upward.
4. **Accumulation of well-built functions** — competence, relationships, understanding — the stack of functions you've constructed through your loops becomes a source of stable positive evaluation.

Happiness is not the absence of negative evaluation. It is **the quality of the functions you've built to process both positive and negative signals**. A person with good functions will experience negative signals and navigate them. A person with poor functions will experience positive signals and fail to sustain them.

（幸福は正の評価の不在ではない。正と負の両方のシグナルを処理するために構築した関数の質。良い関数を持つ人は負のシグナルを経験してもそれを乗り越える。悪い関数を持つ人は正のシグナルを経験してもそれを維持できない。）

## Life as a Wave — 波としての人生

Life is not a line trending upward toward happiness. It is a wave — oscillating between positive and negative evaluation, between dopaminergic pursuit and serotonergic contentment, between comfort and discomfort, between growth and rest.

The wave never flattens. If it did, evaluation would have no reference shift and no signal — which is experienced as numbness, not happiness.

What changes over a well-lived life is not the wave itself but the **functions that ride it**. Better functions mean: the troughs are shallower (you recover faster), the peaks are more deeply felt (you appreciate more fully), and the overall trajectory — while still oscillating — trends toward a richer, more textured experience.

（人生は幸福に向かって上昇する直線ではない。波だ — 正と負の評価の間を振動する。波は平坦にならない。平坦になれば、評価はシグナルを持たず、それは幸福ではなく麻痺として経験される。良く生きた人生で変わるのは波そのものではなく、波に乗る関数。より良い関数は：谷を浅く、山をより深く感じさせ、全体の軌道をより豊かな体験へと向かわせる。）

$$\text{Life} = \int_{0}^{T} \text{evaluation}(t) \cdot \text{function quality}(t)\ dt$$

Not the sum of happy moments. The integral of how well your functions processed every moment — positive and negative alike.
