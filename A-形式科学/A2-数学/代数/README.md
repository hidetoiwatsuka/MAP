# 代数

代数は数の計算規則を抽象化し、一般的な代数的構造を研究します。

## 核となる概念

**演算の構造（代数的構造の公理化）** — 数の足し算・掛け算に見える規則（結合律・単位元・逆元）を抽象化すると、群・環・体という構造が現れる。「どんな計算規則が成り立つか」を公理から解析することで、数・行列・関数・対称変換を同じ枠組みで扱える。
