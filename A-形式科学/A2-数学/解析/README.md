# 解析

解析学は連続的な変化・極限・無限を扱う数学の分野です。微積分を基礎に、実解析・複素解析・関数解析・微分方程式へと展開します。

## 核となる概念

**極限による無限・連続・変化の厳密な記述** — 「限りなく近づく」という直感を ε-δ 論法で厳密に定義することで、微分・積分・級数の理論が崩れなくなる。変化を捉える（微分）・蓄積を捉える（積分）という二つの操作が逆演算になるという微積分の根本定理が、解析学全体の核心。
