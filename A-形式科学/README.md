# A. 形式科学

形式科学は、現実世界の経験的観察に依存せず、純粋な形式的体系（記号・規則・構造）を対象とする学問群です。自然科学・工学・社会科学すべての基盤となります。

## サブカテゴリ

- [A1. 論理学](A1-論理学/README.md) — 正しい推論の形式的研究
- [A2. 数学](A2-数学/README.md) — 数・構造・空間・変化の抽象的研究
- [A3. 計算理論](A3-計算理論/README.md) — 計算の能力と限界の形式的研究

## 他カテゴリとの関係

- 形式科学の道具（微積分・確率・統計）は [B-自然科学](../B-自然科学/README.md) の全分野で使用される
- 計算理論は [D6-情報科学](../D-工学・技術/D6-情報科学/README.md) の土台となる
- 論理学・数理論理学は [G1-哲学](../G-人文学/G1-哲学/README.md) と深く交差する

## 入門のための前提知識

このカテゴリに入門するために最低限知っておくべきこと。

| 領域 | 知っておくべきこと |
|------|-------------------|
| 算数・数の感覚 | 四則演算、分数・小数・百分率の相互変換、比と割合、負の数 |
| 代数の入口 | 変数（xやyで未知数を表す）、一次方程式を解く、関数とは何か（入力→出力の対応） |
| 集合の直感 | 「〜の集まり」という概念、ベン図、「かつ（AND）」「または（OR）」「でない（NOT）」 |
| 論理の基礎感覚 | 「AならばB」の意味、真偽（True/False）の概念、反例を1つ挙げれば主張を崩せること |
| 数の体系 | 自然数・整数・有理数・実数の区別（厳密でなくてよい、「種類がある」と知っていること） |
| 座標 | xy平面上に点を打てる、グラフの読み方（横軸・縦軸が何を表すか） |

> 形式科学は「記号と規則の体系」を扱う分野。変数・論理演算・集合の概念がないと、定義を読むことすらできない。逆に言えば、微積分や線形代数は入門時点では不要（それ自体がA内部の学習対象）。
