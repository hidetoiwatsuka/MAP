# 量子計算理論

量子計算理論は量子力学の原理を利用した計算の理論です。特定の問題で古典コンピュータを指数的に上回る可能性があります。

## 量子ビット（Qubit）

- 状態：|0⟩ と |1⟩ の重ね合わせ |ψ⟩ = α|0⟩ + β|1⟩
- 確率解釈：|α|² + |β|² = 1
- ブロッホ球による幾何的表現
- 多量子ビット系：テンソル積で表現
- 量子もつれ（エンタングルメント）：ベル状態

## 量子ゲート

- ユニタリ変換による量子状態の操作
- 1量子ビットゲート：アダマール（H）、パウリ行列（X, Y, Z）、位相ゲート
- 2量子ビットゲート：CNOT（制御NOTゲート）
- 普遍的ゲートセット
- 量子回路モデル

## 量子アルゴリズム

### ショアのアルゴリズム（1994）
- 整数の素因数分解を多項式時間で解く
- 量子フーリエ変換の利用
- RSA暗号への脅威

### グローバーのアルゴリズム（1996）
- 非構造化データベース検索の二乗根高速化
- O(N) → O(√N)
- 振幅増幅の手法

### その他の量子アルゴリズム
- 位数発見アルゴリズム
- 量子シミュレーション（フェインマンの提案）
- HHLアルゴリズム（線形方程式系）

## 量子誤り訂正

- 量子エラーの性質（ビット反転・位相反転）
- ショアの9量子ビット符号
- スタビライザー符号（Calderbank-Shorのゴッテスマンの形式）
- フォールトトレラント量子計算
- 閾値定理

## 量子暗号

- BB84プロトコル（Bennett-Brassard 1984）
- 量子鍵配送（QKD）の安全性（盗聴を物理的に検出可能）
- 耐量子暗号（格子暗号・符号暗号）
