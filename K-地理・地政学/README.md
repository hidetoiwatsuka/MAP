# K. 地理・地政学

空間・場所・地域を軸に自然・人間・権力関係を研究する学問群。

## サブカテゴリ

- [K1 自然地理](./K1-自然地理.md) — 地形・気候・生物地理・土壌
- [K2 人文地理](./K2-人文地理.md) — 人口・経済・文化・都市地理
- [K3 地政学](./K3-地政学.md) — 権力・領土・エネルギー・サイバー地政学

## 入門のための前提知識

このカテゴリに入門するために最低限知っておくべきこと。

| 領域 | 知っておくべきこと |
|------|-------------------|
| 世界地図 | 7大陸と主要な海洋の名前と位置、赤道・北極・南極の位置 |
| 主要国 | 少なくとも30〜50カ国の名前と大まかな位置（G20 + 主要な地域大国）、首都 |
| 気候帯 | 熱帯・温帯・寒帯・乾燥帯の区別と分布の大枠 |
| 地形 | 山脈・平野・河川・海峡 などの地形用語、主要なもの（ヒマラヤ、アマゾン川、地中海等） |
| 緯度・経度 | 地球上の位置を数字で表す仕組み、時差の概念 |
| 国境と紛争の存在 | 国境は歴史的に決まった人工的なもの、領土問題が存在すること |
| 資源 | 石油・天然ガス・レアメタル等の存在と、偏在していること |
| 歴史の基本（[G-人文学](../G-人文学/README.md)との接点） | 植民地時代の存在、冷戦の構図（東西）、現在の主要な地政学的対立軸 |
| 地球科学（[B-自然科学](../B-自然科学/README.md)との接点） | プレートテクトニクス（地震・火山の原因）の概念、気候変動の概念 |

> 地理は「空間」を軸にした知識体系。世界地図の基本的な読み方、主要国の位置と名前を知らないと、ニュースも論文も読めない。地政学は特に、歴史と地理の交差点にあるため、両方の基礎が必要。
