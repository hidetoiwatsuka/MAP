# F3. 法学

社会規範としての法を研究する学問。法の解釈・立法・執行・比較が主要な営みである。

## 核となる概念

**社会規範の強制可能なルール化** — 法は道徳・慣習・倫理と異なり、国家権力による強制を伴う。「何が法として定められ・どう解釈され・どう適用されるか」というプロセスを問うのが法学の核心。条文の暗記より「なぜその規定が存在するのか」という立法趣旨と利益衡量を理解することが実践的な法的思考につながる。
