# F. 社会制度

人間が集団で生きるために発明した仕組みを研究する学問群。

## 核となる概念

**インセンティブ設計と制度の相互作用** — 経済・法・政治・経営のどの分野も、「人はインセンティブに反応する」という前提の上に成り立っている。制度はインセンティブを変え、インセンティブは行動を変え、行動は制度を変える——この循環を読む力が社会制度の理解の根幹。

## 深さ・学習方針

- **深さ：第2層**
- **理由：** 「お金を稼げる」はここ。クリニック経営、投資判断、法的リスクの評価。
- **具体的に何を：** ミクロ経済（需給・価格・インセンティブ）、会計の基本（PL・BS・CFが読める）、契約と知的財産の基礎、組織設計の原則
- **校正：** 財務諸表を一つ読んで分析する。事業計画を一つ書いてみる。

## 入門のための前提知識

このカテゴリに入門するために最低限知っておくべきこと。

| 領域 | 知っておくべきこと |
|------|-------------------|
| 経済の基本概念 | 需要と供給、価格の決まり方の直感、お金とは何か、インフレとデフレ |
| 政治の基本構造 | 三権分立（立法・行政・司法）、民主主義と権威主義の違い、選挙の意味 |
| 法の基本概念 | 法律は国が定めるルール、権利と義務、契約の概念、犯罪と民事の区別 |
| 国家と主権 | 国家とは何か（領土・国民・主権）、国連の存在、国際関係の概念 |
| 歴史の基本（[G-人文学](../G-人文学/README.md)との接点） | 産業革命、世界大戦（WWI・WWII）、冷戦、グローバリゼーション — 現行制度の成り立ちに直結する歴史イベント |
| 数学（[A-形式科学](../A-形式科学/README.md)からの依存） | グラフの読み書き、百分率、基本的な統計（GDP、成長率の意味） |
| 主要国の名前と位置（[K-地理・地政学](../K-地理・地政学/README.md)からの依存） | G7/G20レベルの国名、EU・NATO・ASEAN等の主要国際機関の存在 |
| 組織の概念 | 会社とは何か、株式会社の基本、雇用関係 |

> 社会制度の学問は「制度がなぜ今の形なのか」を分析する。歴史的経緯と、基本的な経済・政治・法の語彙がないと、議論の出発点に立てない。ニュースを読む程度の時事知識も暗黙の前提になる。
