# F1. 経済学

希少な資源の配分を研究する社会科学。個人の選択（ミクロ）から国民経済全体（マクロ）まで扱う。

## 核となる概念

**希少性とインセンティブ** — 資源は無限にないから選択が生まれ、選択にはトレードオフがある。経済学の全分野（需要と供給・価格・成長・政策）は「人々が希少な資源をどう配分するか、インセンティブに応じてどう行動するか」という問いに帰着する。
